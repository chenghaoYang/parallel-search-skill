## conflicts
- thinking.display 默认：messages 参考「Defaults to summarized.」vs thinking 页「"omitted", the default on many models」（Opus 5.5 等）。
- messages 内 system 角色：参考「there is no "system" role for input messages」vs effort 页（beta mid-conversation-output-config-2026-07-01）「Add a role: "system" message with empty content and the new level in output_config.effort.」
- 兼容层 temperature「Values greater than 1 are capped at 1.」、top_p「Fully supported」vs thinking 页（Opus 5.5/4.7 等）「non-default temperature, top_p, or top_k values return a 400 error on every request」。

## gaps
- 原生 API 无 n：参考页参数表不含 n，未找到明文句子。
- 各页无可见更新日期，仅 featureMetadata status（effort/structured outputs/Files/computer use 为 ga，MCP connector 为 beta）。

## leads
- Files API 已 GA，files-api-2025-04-14 头可选（build-with-claude/files）；container 字段可跨请求复用容器。
- Opus 5.5/Fable 5.1/Mythos 5.1 对 tool_choice any/tool 一律 400（thinking 页）。
- 新响应字段 stop_details（refusal category）、usage.output_tokens_details.thinking_tokens。
- 兼容层 thinking 示例仍用 {"type":"enabled","budget_tokens":2000}，同页称手动 extended thinking 为 legacy。
