## conflicts
- xAI Chat Completions 定性不一："Chat Completions API (Deprecated)"（https://docs.x.ai/developers/model-capabilities/text/comparison）vs "Chat Completions is offered as a legacy endpoint."（https://docs.x.ai/developers/model-capabilities/legacy/chat-completions）；参考页只说 "predecessor"。
- Open Responses 措辞：官网 "based on the OpenAI Responses API"（https://www.openresponses.org/）vs README "inspired by the OpenAI Responses API"（https://github.com/openresponses/openresponses）。

## gaps
- Open Responses 官网/仓库未写"发起方"，只有 maintainer 名单；logo 未标为实现方。
- Mistral API 参考导航未见 /v1/responses 或 /v1/messages，无官方否定句。
- 未专门检索 8 家有无 Gemini generateContent 兼容端点。
- SGLang 文档未见 /v1/responses 说明页，仅代码路由。
- Bedrock 页面无可见更新日期。

## leads
- Bedrock：bedrock-runtime 上 Responses 仅同步、无服务端工具；GPT OSS 的 Responses 只在 mantle（inference-responses-api.html）。
- OpenRouter Responses 仅无状态：store:true 或 previous_response_id 会 400。
- Ollama Anthropic 兼容不支持 tool_choice、cache_control、batches、citations、PDF；SGLang 另有 Ollama 兼容 /api/chat。
- Mistral：POST /v1/agents/completions 在 "Deprecated" 分组；chat 另有 prompt_mode、reasoning_effort。
- xAI 与 Open Responses（2026-04-24）均支持 WebSocket 版 Responses。
