## conflicts
- store 默认值：spec 为 "store: type: boolean default: false"（https://github.com/openai/openai-openapi/blob/main/openapi.yaml）；迁移指南 "Chat completions are stored by default for new accounts."（https://developers.openai.com/api/docs/guides/migrate-to-responses）

## gaps
- platform.openai.com 返回 403，改用 developers.openai.com 与 spec；指南页无更新日期。
- 无原句明说 stored completion 不能续聊；请求 schema 无引用字段（推断）。
- 缓存指南示例只有 Responses；Chat 的 cached_tokens 位置仅据 spec。
- GPT-5.6+ 是否接受 prompt_cache_retention 不清：spec 称 "future models, only `24h` is supported"，指南对 5.6+ 只列 prompt_cache_options.ttl。
- deprecations 页（最新 2026-09-11）无 Chat Completions 条目，未见弃用计划。

## leads
- 推理指南：GPT-6 Astra 上 reasoning_effort:none 返回 HTTP 400；Chat 不支持其函数调用。
- content part 新增 prompt_cache_breakpoint{mode:"explicit"}（gpt-5.6+）；GPT-5.6 前 cached_tokens 向下取 128 的倍数。
- Chat 新增 moderation 参数与 stream_options.include_obfuscation；openai-python v3.19.0 遇 "[DONE]" 即停止。
