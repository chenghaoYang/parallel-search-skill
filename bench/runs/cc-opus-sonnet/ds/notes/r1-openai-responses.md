# r1-openai-responses
question: OpenAI Responses API（POST /v1/responses）的官方规格在 D1–D10 上各是什么？以及官方迁移指南列出的它相对 Chat Completions 的差异。
checked: https://developers.openai.com/api/docs/api-reference/responses/create, https://developers.openai.com/api/docs/guides/{migrate-to-responses,conversation-state,streaming-responses,reasoning,tools}, https://github.com/openai/openai-openapi/blob/master/openapi.yaml, https://github.com/openai/openai-python/tree/main/src/openai/types/responses

- [C2] D2: input为字符串或数组(文本/图像/文件)；instructions为插入上下文的系统/developer消息 | src: https://github.com/openai/openai-openapi/blob/master/openapi.yaml | quote: "Text, image, or file inputs to the model, used to generate a response." | type: official
- [C3] D2: Item类型除message外含reasoning、function_call、function_call_output；role枚举user/system/developer/assistant；content含input_text/input_image/input_file/output_text | src: https://developers.openai.com/api/docs/guides/migrate-to-responses | quote: "alongside Items such as reasoning, function_call, and function_call_output" | type: official
