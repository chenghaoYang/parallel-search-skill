# r1-openai-responses
question: OpenAI 官方 Responses API（/v1/responses）的请求与响应协议长什么样，和 Chat Completions 的字段差在哪？
checked: https://developers.openai.com/api/reference/resources/responses/methods/create/, https://developers.openai.com/api/reference/overview/, https://developers.openai.com/api/docs/guides/migrate-to-responses, https://developers.openai.com/api/docs/guides/conversation-state, https://developers.openai.com/api/reference/resources/responses/streaming-events

## claims
- [C1] D1：生成端点写为 post /v1/responses。 | src: https://developers.openai.com/api/docs/guides/migrate-to-responses | quote: "Start by updating your generation endpoints from `post /v1/chat/completions` to `post /v1/responses`." | type: official
- [C2] D1：鉴权头为 Bearer。 | src: https://developers.openai.com/api/reference/overview/ | quote: "Authorization: Bearer OPENAI_API_KEY_OR_ACCESS_TOKEN" | type: official
- [C3] D2：previous_response_id 是上一则 response 的 id。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "The unique ID of the previous response to the model." | type: official
- [C4] D2：conversation 的 items 前置到本次 input_items。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "Items from this conversation are prepended to `input_items` for this response request." | type: official
- [C5] D2：不传会话 id 时，单次文本生成请求无状态，历史要放进本次参数。 | src: https://developers.openai.com/api/docs/guides/conversation-state | quote: "While each text generation request is independent and stateless, you can still implement multi-turn conversations by providing additional messages as parameters to your text generation request." | type: official
- [C6] D3：input 的 string 等于 role 为 user 的文本。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "A text input to the model, equivalent to a text input with the `user` role." | type: official
- [C7] D3：EasyInputMessage.role 为 user、assistant、system、developer。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "The role of the message input. One of `user`, `assistant`, `system`, or `developer`." | type: official
- [C8] D3：函数调用 item 的 type 恒为 function_call。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "The type of the function tool call. Always `function_call`." | type: official
- [C9] D5：工具结果回传 type 恒为 function_call_output。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "The type of the function tool call output. Always `function_call_output`." | type: official
- [C10] D4：instructions 是 system 或 developer 消息。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "A system (or developer) message inserted into the model's context." | type: official
- [C11] D5：web search 的 type 为 web_search 或 web_search_2025_08_26。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "The type of the web search tool. One of `web_search` or `web_search_2025_08_26`." | type: official
- [C12] D6：max_output_tokens 含可见输出和 reasoning tokens。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "An upper bound for the number of tokens that can be generated for a response, including visible output tokens and reasoning tokens." | type: official
- [C13] D6：temperature 为 0 到 2。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "What sampling temperature to use, between 0 and 2." | type: official
- [C14] D6：reasoning.effort 为 none、minimal、low、medium、high、xhigh、max。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "Constrains effort on reasoning for reasoning models. Currently supported values are `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, and `max`." | type: official
- [C15] D7：stream true 时走 server-sent events。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "If set to true, the model response data will be streamed to the client as it is generated using server-sent events." | type: official
- [C16] D8：非流式正文在 output 数组。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "An array of content items generated by the model." | type: official
- [C17] D8：status 为 completed、failed、in_progress、cancelled、queued、incomplete。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "The status of the response generation. One of `completed`, `failed`, `in_progress`, `cancelled`, `queued`, or `incomplete`." | type: official
- [C18] D8：usage 含 input tokens、output tokens 与 total tokens。 | src: https://developers.openai.com/api/reference/resources/responses/methods/create/ | quote: "Represents token usage details including input tokens, output tokens, a breakdown of output tokens, and the total tokens used." | type: official
- [C19] D9：结构化输出字段是 text.format，不是 response_format。 | src: https://developers.openai.com/api/docs/guides/migrate-to-responses | quote: "Instead of `response_format`, use `text.format` in Responses." | type: official
- [C20] D10：Chat Completions 仍支持；新项目推荐 Responses。 | src: https://developers.openai.com/api/docs/guides/migrate-to-responses | quote: "While Chat Completions remains supported, Responses is recommended for all new projects." | type: official
