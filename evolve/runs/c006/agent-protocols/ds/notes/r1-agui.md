## claims
- [C1] AG-UI 连接「AI agent ↔ 面向用户的前端应用」：协议自述为 "an open, lightweight, event-based protocol that standardizes how AI agents connect to user-facing applications"；spec 进一步归纳为 "one request in, one ordered stream of typed events out"，双方角色为 producer（发事件流）/ consumer（读流）。| src: https://docs.ag-ui.com/ ; https://docs.ag-ui.com/spec/1.0/index.md | quote: "one request in, one ordered stream of typed events out" | type: official
- [C2] 发起方与治理：CopilotKit 于 2025-05 创建（博客首篇 "Introducing AG-UI" 2025-05-12），MIT license，仓库在 github.com/ag-ui-protocol/ag-ui（约16k stars），有 "Biweekly AG-UI Working Group" 与公开 roadmap；仍由 CopilotKit 主导、未移交基金会（对比 MCP→AAIF 2025-12、A2A→LF 2025-06）。| src: https://www.copilotkit.ai/learning/mcp-vs-a2a-vs-ag-ui ; https://github.com/ag-ui-protocol/ag-ui | quote: "AG-UI was created by CopilotKit (May 2025) and is developed in the open under the MIT license with the major agent frameworks." | type: official
- [C3] Spec 形态：docs.ag-ui.com（ag-ui.com 301 跳转至此）；仓库 spec/1.0/ 目录，JSON Schema Draft 2020-12 为权威结构，schema URI https://ag-ui.com/spec/1.0/schema.json，另有 fixtures 与 test harness。| src: https://github.com/ag-ui-protocol/ag-ui/tree/main/spec | quote: "the file validates against the 2020-12 meta-schema" | type: official
- [C4] 传输：协议 transport-agnostic，spec 1.0 规定两个 normative binding——HTTP+SSE（POST JSON RunAgentInput，Accept: text/event-stream，响应 "Each SSE event's `data` payload is exactly one protocol event as a JSON object"，无 stream resumption）与 HTTP+Protobuf 二进制 wire（length-prefixed frames）；概念页另提 WebSockets、webhooks 均可用。| src: https://docs.ag-ui.com/spec/1.0/basic/transports/http-sse.md ; https://docs.ag-ui.com/concepts/architecture | quote: "supporting various transport mechanisms including Server-Sent Events (SSE), webhooks, WebSockets, and more" | type: official
- [C5] 事件清单：1.0 spec 组织为 "the eight event families"，docs 列出约 31 个标准事件：lifecycle 5（RUN_STARTED/RUN_FINISHED/RUN_ERROR/STEP_STARTED/STEP_FINISHED）、text message 4（TEXT_MESSAGE_START/CONTENT/END/CHUNK）、tool call 5（TOOL_CALL_START/ARGS/END/RESULT/CHUNK）、state 3（STATE_SNAPSHOT/STATE_DELTA/MESSAGES_SNAPSHOT）、activity 2、reasoning 7（REASONING_*）、subagent 3（SUBAGENT_STARTED/FINISHED/ERROR）、special 2（RAW/CUSTOM）；另有 draft META_EVENT 与 5 个已废弃 THINKING_*。| src: https://docs.ag-ui.com/concepts/events | quote: "STATE_SNAPSHOT, STATE_DELTA, MESSAGES_SNAPSHOT" | type: official
- [C6] 核心抽象：RunAgentInput 为唯一入参（fields: threadId/runId REQUIRED、parentRunId、protocolVersion、messages REQUIRED、tools 即 frontend tools、context、state、forwardedProps、resume）；BaseEvent 携带 type/timestamp/rawEvent；类型含 Message（可带多模态 ContentPart）、State（JSON object）、Tool（name/description/parameter schema）、Context（description–value pairs）；STATE_DELTA 用 JSON Patch RFC 6902。| src: https://docs.ag-ui.com/spec/1.0/basic/run-input.md ; https://docs.ag-ui.com/concepts/architecture | quote: "`threadId` names the conversation and `runId` names the run this input requests; both are REQUIRED." | type: official
- [C7] 鉴权：spec 不定义 authn/authz 机制——http-sse 绑定只在拒绝原因里提 "refused auth"；spec index 将安全限定为信任原则（"Model output is untrusted input"、"The protocol itself cannot enforce these principles"）；实现层由 HttpAgent 的 `headers?: Record<string,string>` 传 Bearer token 等。| src: https://docs.ag-ui.com/spec/1.0/basic/transports/http-sse.md ; https://docs.ag-ui.com/sdk/js/client/http-agent.md | quote: "Authorization: \"Bearer your-api-key\"" | type: official
- [C8] 版本：当前 spec 版本 1.0（"the first release with a specification behind it"），npm @ag-ui/core 1.0.0 发布于 2026-09-17，仓库用 date-tagged releases（最新 release/2026-09-23）；1.0 变更含 RUN_FINISHED outcome、subagents、reasoning 取代 THINKING_*、ACTIVITY_*、二进制 wire、AgentCapabilities、in-band `protocolVersion` 协商。| src: https://docs.ag-ui.com/migrating-to-1-0.md ; https://registry.npmjs.org/@ag-ui%2fcore ; https://docs.ag-ui.com/spec/1.0/changelog.md | quote: "The specification exists" | type: official
- [C9] 与 MCP/A2A 定位：官方称 "These three agentic protocols are complementary and have distinct technical goals"——"MCP ... Connects agents to tools and to context"、"A2A ... Connects agents to other agents"、"AG-UI ... Connects agents to users"；并支持 "handshakes, allowing AG-UI to 'front for' agents through MCP and A2A protocols"。| src: https://docs.ag-ui.com/agentic-protocols.md | quote: "AG-UI has emerged as the 3rd leg of the AI protocol landscape." | type: official
- [C10] 大厂采用：Microsoft Agent Framework 宣布 AG-UI 兼容（CopilotKit 博客 2025-11-11）；Google ADK、AWS Strands Agents、AWS Bedrock AgentCore（2026-03 宣布 dedicated AG-UI endpoint）列为 first-party；Oracle 将 AG-UI 纳入 Agent Spec（2025-12-18）；OpenAI Agent SDK、Cloudflare Agents 标为 in progress。| src: https://www.copilotkit.ai/blog ; https://docs.ag-ui.com/ | quote: "Microsoft Agent Framework is now AG-UI Compatible!" | type: official
- [C11] 代表实现：官方 SDK——TS（@ag-ui/core、@ag-ui/client 的 HttpAgent）、Python（ag-ui-protocol 包）、.NET、Kotlin、Go、Dart、Java、Rust、Ruby、C++；集成框架 LangGraph/LangChain、CrewAI、Mastra、Pydantic AI、Agno、LlamaIndex、AG2；客户端 CopilotKit、terminal、Slack/Teams、React Native；A2A middleware 可把 A2A agent 包成 AG-UI。| src: https://docs.ag-ui.com/ ; https://github.com/ag-ui-protocol/ag-ui | quote: "Connect to any protocol by implementing `run(input: RunAgentInput) -> Observable<BaseEvent>`" | type: official

## conflicts
- 事件总数口径漂移：GitHub README 仍写 "~16 standard event types"，CopilotKit 博客 2025-11 写 "17 AG-UI Event Types"，而 docs/spec 1.0 实际列出约 31 个（含 1.0 新增 reasoning/subagent/activity 家族）。README 大概率未随 1.0 更新。

## gaps
- spec 1.0 的正式公布日期无明文：changelog/migrating 页均无日历日期，npm 1.0.0（2026-09-17）是最接近的锚点。
- 是否计划移交中立基金会：官方未表态；GitHub issue #1223 有社区提议移交 LF，未被官方采纳记录。
- spec 文本中未检索到 WebSocket 的 normative binding（仅概念页列举可用传输）。
