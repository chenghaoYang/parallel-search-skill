## conflicts
- 无实质冲突。注意命名撞车：Zed 的 ACP=Agent Client Protocol（2025-08），OpenAI/Stripe 的 ACP=Agentic Commerce Protocol（2025-09），互不相关。

## gaps
- Anthropic 对 A2A/AG-UI/ACP 无官方表态：查了 anthropic.com/news/model-context-protocol、claude.com/blog/integrations，均未提及其他协议。
- OpenAI 对 AG-UI 与 Zed ACP 无官方表态；Altman 原推文无法直接取（x.com 402），日期取自官方论坛转述。
- Apps SDK「built on MCP」原话：openai.com DevDay 公告页 403 未取到，用 help.openai.com「Apps SDK and Model Context Protocol」代替。
- Gemini CLI 走 ACP 仅有 Zed 侧一手来源；google.com 侧公告未找到（Android Central 提到 press release）。
- 微软是否采用 Zed ACP / AG-UI 客户端角色之外的协议细节未深挖。
