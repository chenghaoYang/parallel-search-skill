## conflicts
- r1 主张「WebSocket 只在概念页列举」与 spec 原文冲突：transports/index.mdx（normative）明列 WebSockets 为允许的 custom transport 通道并施加 binding contract（C5）；schema.json TransportCapabilities.websocket 是 normative schema 字段（C6）。应改写为「无 WS normative binding；WS 仅以 (a) custom transport 合法通道、(b) schema 能力 flag 出现」。实质主张「binding 只有 HTTP+SSE 与 HTTP+Protobuf」维持（C4）。
- 无官方文档间互相矛盾。
