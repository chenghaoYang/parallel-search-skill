## conflicts
- 无实质冲突。命名沿革注意：README 表写 "HIP (AMD GPU)"（源码目录 ggml-hip），旧文档/二手资料常称 hipBLAS/ROCm 后端——同一后端的新名。Kompute 已删（C15），Vulkan 是现役 GPU 后端。

## gaps
- "不能直接加载 safetensors" 无逐字原句：docs/models.md 只说 "requires the model to be stored in the GGUF file format" + "other data formats can be converted"（未点名 safetensors）；convert_hf_to_gguf.py 的存在间接证实 HF→GGUF 转换路径。
- radix tree / PagedAttention 式块表：官方文档未使用这些术语；前缀复用机制是 per-slot 前缀相似度匹配 + KV shifting + 可选统一 KV buffer（C2/C4-C6），与 vLLM 的 radix/paged 方案差异属综合判断，无官方对照表述。
- 各后端成熟度/算子覆盖矩阵未逐文档核对（docs/backend/ 下有 CANN.md, SYCL.md, OPENCL.md, OPENVINO.md, zDNN.md, ZenDNN.md, BLIS.md, VirtGPU.md, ET.md, snapdragon/ 等）。
- RPC 后端跨机推理的具体配置（tools/rpc）未展开。
