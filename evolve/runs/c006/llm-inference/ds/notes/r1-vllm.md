## conflicts
- APC 默认态文档自相矛盾：feature 页写 "Set enable_prefix_caching=True in vLLM engine to enable APC"（暗示默认关），而 engine_args/源码为 V1 默认开；官方 PR #54903（[Docs] Clarify APC is enabled by default）承认 feature 页过时并修正。以 engine_args/代码为准。
- 投机解码方法集随版本漂移：README 写 "n-gram, suffix, EAGLE, DFlash"，docs latest 页列 EAGLE/MTP/draft/PARD/MLP/N-gram/Suffix，两边口径不完全一致（README 无 MTP/PARD/MLP 字样）。

## gaps

- GGUF 细节限制未枚举：支持的 quant 类型清单、单文件/分片限制、dtype 约束官方页未写。
- 安装页未给各硬件成熟度分级（仅 Apple/TPU 走插件隐含差异）。
