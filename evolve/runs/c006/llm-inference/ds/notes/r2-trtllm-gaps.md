## conflicts
- r1 记录的 support-matrix Blackwell 行真实存在但只在 v1.0.0 版文档（"Blackwell (SM100/SM120) - FP32, FP16, BF16, FP8, FP4, INT8, INT4"），是 TensorRT 后端时代的矩阵；1.1.0rc5 起该行被删、整页在 ≥1.1.0 版文档移除。1.3 quantization 页硬件矩阵无 INT8/INT4 列。两页都 official，差异是版本差异：当前 PyTorch 后端口径以 quantization 页为准（Blackwell 无 INT8/INT4）。
- 简报怀疑 Medusa/Lookahead/ReDrafter 随 v1.2 TensorRT 后端删除——反证：v1.2.0/v1.2.1 源码树仍有全部三类文件，API 类活到 1.3.0rc25，实际完成移除在 ~v1.3.0rc26（TRTLLMSampler 移除系列 PR #18232/#18233/#18532）。功能在 v1.2 后可能已死（无 TensorRT 后端可执行），但代码/配置类存活。

## gaps
- Medusa/Lookahead 在 v1.2–v1.3.0rc25 期间配置类标记 "stable" 但 PyTorch 后端是否真能跑未验证（_torch/speculative/ 目录即使在 rc25 也无 medusa/lookahead worker 文件——很可能已不可用，仅 API 残留）。
- release notes 全文 grep 无任何一条显式 "removed Medusa/Lookahead/ReDrafter" 语句（查过 release-notes.html 全部版本段）。
- ReDrafter 具体删除 commit 未逐一锁定（examples/redrafter 由 #15763 删，models/redrafter 等由 #16369 或中间 commit 删，残余 redrafterCurandOp.cpp 由 rc25→rc26 间 commit 删）。

## leads
- TRTLLMSampler/sampler_type 移除（#18232, BREAKING）是 1.3.0rc26 的另一重大 API 变更，若 grid 有 sampler 维度可用。
- support-matrix.html 整页在 ≥1.1.0 文档已消失，引用该页应注明版本前缀 URL（如 /1.0.0/...）。
