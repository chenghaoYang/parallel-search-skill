## conflicts
- 弃用措辞时间线：2025-03-26 changelog 只说 "Replaced the previous HTTP+SSE transport"（未用 deprecated 一词）；「deprecated」标签首见于 2025-06-18 transports 页 "the deprecated HTTP+SSE transport"；2026-07-28 changelog/deprecated registry 追认 "deprecated since protocol version 2025-03-26"。三者方向一致，但「2025-03-26 起即废弃」属追认口径。

## gaps
- 2026-07-28 revision 除版本号即日期外，未见独立 release 公告确认发布日；spec 站默认指向 2026-07-28，视为 current。
- HTTP+SSE 移除时点 "Three months after SEP-2596 reaches Final"：SEP-2596 当前状态（是否 Final）未核。
- MCP Registry（官方社区注册表，server.json）细节未展开——Anthropic 公告仅称 "official, community-driven Registry for discovering available MCP servers"。
