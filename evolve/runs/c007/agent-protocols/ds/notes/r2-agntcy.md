## conflicts
- 无文档间冲突。值得注意的张力：LF 公告（2025-07）把 AGNTCY 说成与 A2A "interoperable"，但当时 ACP 仍是其自有调用协议；到 2026-04 acp-spec/acp-sdk 归档后，AGNTCY 事实上放弃了自有调用协议，转为给 A2A 做 SLIM 传输+目录发现——官方从未明说 "ACP deprecated/superseded by A2A"，只有归档行为和 issue #48 旁证。

## gaps
- 没有任何官方页面明确写 "ACP is deprecated/replaced by A2A"——已查 acp-spec README、docs.agntcy.org 全 sitemap、agntcy.org、spec.acp.agntcy.org、org profile，均无此句；结论只能靠归档+slim-a2a-* 推断。
- acp-spec 归档具体日期（2026-04-11）来自 GitHub UI 提示语，API archived_at 字段未直接返回；二次fetch确认过。
- OASF 版本号/DIR 对 A2A agent card 的原生支持程度未逐字核到（dir README 只提 OASF records + MCP server 链接，未提 A2A）。

## leads
- AGNTCY 现栈一行版：SLIM（消息传输，含 slim-a2a-* 给官方 a2a-sdk 做传输）、DIR+OASF（目录/能力schema）、Identity、Observe；AgentBridge 走 A2A。
- outshift.cisco.com/the-internet-of-agents/agntcy 提到 AGNTCY 组件已进入 "AAIF, the A2A protocol and the Agentic Resource Discovery (ARD) specification" 等更广社区——如需 AGNTCY→AAIF/LF 归属演变可再挖。
