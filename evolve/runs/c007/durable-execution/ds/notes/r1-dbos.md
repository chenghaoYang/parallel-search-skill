## conflicts
- 无实质冲突。注意 exactly-once 措辞仅用于「workflow 级入口」（idempotency key、调度、消息投递、事件处理），step 副作用官方明确是 at-least-once——二者口径不同不矛盾，但对比文档别混用。

## gaps
- 未找到 DBOS.random / DBOS.now / DBOS.uuid 之类确定性 helper API：已查 python workflow-tutorial、typescript workflow-tutorial、python reference/contexts，均无；官方做法是「非确定性操作放进 step」。
- 现行 Python 调度 API 是 DBOS.create_schedule 而非 @DBOS.scheduled 装饰器；旧版 scheduler_mode/@DBOS.scheduled 是否仍存在未确认（当前页未提）。
- Go/Java SDK 成熟度（beta/GA）官方无明示，README 无成熟度声明。
- DBOS Cloud 价格未公开。
- TS/Go/Java 的 step 重试参数名、patch API 名与 Python 可能不同，未逐一核。

## leads
- operation_outputs 表是 workflow history/patch marker 的载体（升级页），对「Postgres 表结构」深挖有用。
- Conductor 功能含 fork/replay/version 管理（pricing 页），可作工作流运维维度线索。
