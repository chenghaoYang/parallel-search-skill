## conflicts
- GitHub 对 inngest-js 仓库的 license 检测显示 GPL-3.0，但 packages/inngest/LICENSE.md 为 Apache-2.0 全文且 package.json "license": "Apache-2.0"；README 亦声明 "All Inngest SDKs are all available under the Apache 2.0 license." → 仓库级检测为陈旧元数据，SDK 实际 Apache-2.0。
- self-hosting 页不列 cloud-only 功能（C12），但 MCP 页明确存在 "Cloud-only tools"（C13）→ 文档口径不一致，实际 Insights/环境/webhook/key 管理等为 cloud-only。

## gaps
- "exactly once / at least once" 措辞：how-functions-are-executed 页通篇无此短语（二次定向抓取确认）；at-least-once 语义只能从"重试+事件默认重复触发"推断。
- SSPL 非 OSI 批准、是否影响"商用自托管内部使用"：LICENSE 文本即标准 SSPL，§13 只约束对外提供服务；官方未另出 FAQ 解释。
- Java/Kotlin SDK (inngest-kt) 在 docs 中的官方程度不明：learn 页只提 TS/Python/Go，仓库存在且活跃，docs 未检索到对应 reference 页。
- inngest-rs 状态（实验性/社区）未确认。
- Free/Pro 各维度数值以抓取日（2026-09）为准，未记录页面更新日期。
