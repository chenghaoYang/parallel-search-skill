## conflicts
- 2.5 Flash 最小 token：2025-05-08 公告=1,024（C26）；当前文档表=2,048（C3）。文档页 Last updated 2026-09-11，应以后者为准，但值发生过变化。
- 命中折扣：公告称 "75% token discount"（C27）；当前价目 cached 价恰为输入价 10%（≈90% off，如 2.5 Flash $0.03 vs $0.30，C9）。折扣力度已加深。
- explicit 模型范围：公告（2025-05）写 "Gemini 2.5 and 2.0 models"；当前文档写 "most models" 且示例用 3.8 Flash——范围已扩。

## gaps
- explicit caching 的最小 token 具体数值：页面只在 Implicit caching 节内给出数值表；explicit 节仅"varies by model"。
- implicit 缓存在 Gemini API 的存活时长/TTL 未文档化（Vertex 侧为 ≤24h，见 leads）。
- implicit 是否可关闭：文档只写"enabled by default…nothing you need to do"，无 disable 字段。
- implicit 命中是否要求逐字节相同前缀、多长窗口：文档仅给"similar prefix"+"short amount of time"建议。
- usageMetadata 是否还有 cacheTokensDetails 等细分字段：API ref 页截断，未逐字确认。
