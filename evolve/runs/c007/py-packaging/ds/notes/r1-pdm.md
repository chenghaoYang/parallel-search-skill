## conflicts
- pep582 页称 "When the project interpreter is a normal Python, this mode is enabled"，与 venv 页 "virtualenv is the default mode if not configured otherwise" 表面矛盾；实际由 `python.use_venv` 默认 True 调和（默认解释器被换成 .venv，故 582 不生效）。非真正冲突，但 pep582 页措辞易误读为「普通 Python 即默认启用 582」。

## gaps
- pep621 参考页未枚举 [project] 必填字段（name 是否可 dynamic 未明示）。
- `pdm install` 直接消费独立 pylock.toml（不设 lock.format）是否支持未逐字确认；仅从「pylock 为锁格式」推得。
- PEP 582 拒绝的确切日期：头部无日期，仅 resolution 链接 Discourse message #430。
- setup-pdm 缓存的具体内容（装好的依赖还是 PDM 本体）README 未明说。
