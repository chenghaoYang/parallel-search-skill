## conflicts
- poetry-plugin-export README 内部不一致：格式列表含 pylock.toml，但旧注仍写 "only the `constraints.txt` and `requirements.txt` formats are available"（https://github.com/python-poetry/poetry-plugin-export）。

## gaps
- poetry.lock 文件内部格式（metadata lock-version、content-hash 字段）官方文档未正式描述；仅在 basic-usage 有行为级说明。
- pylock.toml 的 import（读入/锁定）支持：poetry CHANGELOG 与 plugin CHANGELOG/README 均只见 export，未见 import 条目；未见官方页面明确说"不支持 import"。
- pyproject.md 正文未写 [project] 支持的最低版本号；版本起点取自 CHANGELOG 2.0.0 与 dependency-specification 页的 "With Poetry 2.0"。
- 无专门 GitHub Actions CI 缓存指南；官方仅 FAQ 的 Docker 层缓存建议 + POETRY_CACHE_DIR。
