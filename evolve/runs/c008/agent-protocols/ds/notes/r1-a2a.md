## conflicts
- GitHub README 仍写 "Standardized Communication: JSON-RPC 2.0 over HTTP(S)"（单一传输），而 v1.0 spec 定义三个并列 binding 且不要求单一默认——README 表述滞后于 v1.0。src: https://github.com/a2aproject/A2A vs https://raw.githubusercontent.com/a2aproject/A2A/main/docs/specification.md

## gaps
- spec 未规定必须实现的默认 binding（仅要求 AgentCard 声明 + 功能等价）；无 "MUST support JSON-RPC" 类语句（§5.1/§5.2 原文已核）
- Google 2025-04 首次发布的具体日期（约 4/9，developers.googleblog.com 原文未取）
- ACP 并入后其在 LF AI & Data 的项目状态是否正式 archived，未找到书面声明
- spec §9.1/10.1/11.1 各 binding 的强制实现范围细节未逐条核
