## conflicts
- Anthropic 捐赠博文称 "the November 25th spec release introduced ... asynchronous operations, statelessness, server identity, and official extensions"；但官方 2025-11-25 changelog 只列了实验性 tasks、OIDC discovery 等，"Make MCP stateless / remove initialize handshake" 实际出现在 2026-07-28 changelog。博文对版本归属的描述与 changelog 不一致（可能把 11-25 之后特性笼统归到该发布线）。两处原文：博文见 C17 src；changelog 见 https://modelcontextprotocol.io/specification/2025-11-25/changelog 与 https://modelcontextprotocol.io/specification/2026-07-28/changelog。

## gaps
- 2024-11-05 首版 changelog 原文未单独取（官网该版无 changelog 页；公开发布日 2024-11-25 来自 LF 新闻稿间接表述，未取 Anthropic 原始公告页）。
