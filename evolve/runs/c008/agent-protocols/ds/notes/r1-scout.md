## conflicts

- AG-UI 治理：LF/OpenAI 一手公告的 AAIF 创始项目仅 MCP/goose/AGENTS.md，AG-UI 不在其中；secondary（ai2.work）称其仍归 CopilotKit。若主文档假设 AG-UI ∈ AAIF 则需修正。
- AGNTCY 归属：VentureBeat 称 Cisco「donated AGNTCY to the foundation」，语境似指 LF 体系；AAIF 官方名单不含它，footer 为 LF Projects LLC 独立 series——不要写成 AAIF 项目。

## leads
- UCP（Google+Shopify，commerce 层，2026-01）——简报候选之外的新协议，agentic commerce 用户必遇，建议入 grid。
- AP2 标准化路径已转 FIDO Alliance（TWG）；x402 已入 LF x402 Foundation（40 成员含 Visa/MC/Stripe）——支付层两协议治理都已中立化，与「商业方案」（Visa Intelligent Commerce / Mastercard Agent Pay）区分开。
- WebMCP 是浏览器层 MCP 类比物（W3C CG draft，仅 Chromium），用户极易与 MCP 混淆。
- AGNTCY 子组件（SLIM/OASF/Agent Directory/Identity）本身是可入 grid 的标准化产物；Cisco 系 ACP 若种子词指 IBM ACP 需区分。
- MCP Registry 是 MCP 生态官方目录（preview, API v0.1 freeze），属「标准化产物」而非协议。
- AAIF（2025-12-09, LF directed fund）统一 MCP/goose/AGENTS.md 治理；A2A 2025-06 直捐 LF、AGNTCY 在 LF Projects、AG-UI 仍归 CopilotKit——治理归属不一，写 grid 治理列时需逐条分开。
