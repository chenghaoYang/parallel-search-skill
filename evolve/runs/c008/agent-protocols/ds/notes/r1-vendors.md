## claims
- [C1] OpenAI 官方 MCP 指南：MCP 是 "an open protocol that's becoming the industry standard for extending AI models with additional tools and knowledge"；覆盖 ChatGPT 插件（"through a plugin in ChatGPT and Codex"）、deep research/company knowledge（search+fetch 工具）、Responses API（`type: "mcp"` 工具 + `server_url`/`allowed_tools`/`require_approval`）。 | src: https://developers.openai.com/api/docs/mcp | quote: "You can test the MCP server using the Responses API directly" | type: official
- [C2] OpenAI Apps SDK/插件体系以 MCP 为中心（2026 版文档已改称 plugins）。 | src: https://developers.openai.com/apps-sdk/ | quote: "Build and publish plugins with skills, MCP servers, and optional UI." / "Connect your plugin to tools, data, and services through the Model Context Protocol." | type: official
- [C3] Agentic Commerce Protocol (ACP) 由 OpenAI 与 Stripe 共同开发，Apache 2.0 开源，OpenAI 是首个实现方（ChatGPT）。 | src: https://www.agenticcommerce.dev/ | quote: "Stripe and OpenAI developed the Agentic Commerce Protocol" / "ACP is open source and community-designed under the Apache 2.0 license" / "OpenAI is the first AI platform to implement ACP with ChatGPT" | type: official

## conflicts
- 无实质性冲突。命名注意：OpenAI 的 ACP=Agentic Commerce Protocol（电商），与 IBM/BeeAI 的 ACP=Agent Communication Protocol（已并入 Linux Foundation A2A 系）同名不同物；Google 另有 UCP 与 AP2 同赛道。

## gaps
- Anthropic 对 A2A/AG-UI 的官方态度：本轮查过的 Anthropic 页面（MCP 发布、Integrations、MCP connector 文档）均未提 A2A/AG-UI；未见官方支持，但未做排他性全网核查。
- AG-UI（CopilotKit）：四家官方页面均未检索到支持声明；Google 走的是自家 A2UI（见 leads）。
- OpenAI 的 ChatGPT 侧 A2A 支持：仅证实 SDK 层拒绝（C4）；openai.com/index 全站 Cloudflare 403，launch 博文（Apps SDK、Buy it in ChatGPT、connectors）未能取原文。
- "ChatGPT connectors 支持 MCP" 的原始公告页未取到；现有证据为开发者文档中的 plugins/deep research 表述（C1）。

## leads
- Amazon Bedrock AgentCore（2025-07 发布）官方宣称支持 MCP（AgentCore Gateway），可作第五家 bonus——本轮未取一手页。
- Google "A2Family"：除 AP2 外还有 UCP（Universal Commerce Protocol，20+ 伙伴共建，驱动 Search AI Mode/Gemini 内购买，对标 OpenAI ACP）与 A2UI（agent→UI 渲染协议，对标 AG-UI）。见 https://opensource.googleblog.com/2026/04/meet-the-a2family.html 与 https://developers.googleblog.com/under-the-hood-universal-commerce-protocol-ucp/
- AP2 后续已捐 FIDO Alliance 标准化（AP2 v0.2，github.com/google-agentic-commerce/ap2 docs/index.md）。
