## conflicts
- implicit 最小门槛：当前页（Last updated 2026-09-02）写 Gemini 2.5 Flash = 2,048（https://ai.google.dev/gemini-api/docs/caching）；2025-05-17 版与官方博客写 2.5 Flash = 1,024（"we reduced the minimum request size for 2.5 Flash to 1024"）。门槛上调过，当前以 2,048 为准，但属版本漂移需注明日期。
- implicit 折扣：2025-05-08 官方博客 "the same 75% token discount"；当前价目表 cached 价 = 输入价 10%（90% 折扣），Vertex 页明写 90%。折扣力度后来加大，引用需带日期。

## gaps
- D8 Gemini API（AI Studio 侧）无官方 isolation/共享声明；只有 Vertex 的 project/VPC-SC 说法可引。
- D3 implicit 缓存具体存活时间官方未写（仅 "a short amount of time"）。
- 当前页不再列 explicit caching 最小 token（仅 implicit 表）；2025 版两句同值（1024/2048）可引但属旧版。
- implicit 无官方 opt-out 开关的正面声明（docs 只写 "There is nothing you need to do in order to enable this"）。
