## conflicts
- F2 被推翻（绝对形式）：「OpenRouter 不自建/不存储缓存」不成立——Response Caching 在 OpenRouter 层存储响应（C4 原句）。限缩为「prompt caching 在上游 provider」则仍成立（C3）。
- F5 被推翻（绝对形式）：「implicit caching 无开关/无法关闭」对 Vertex 不成立——项目级 cacheConfig disableCache 存在（C12）。对 Gemini API（ai.google.dev）页面未见关闭表述，仅 silence（C11），该限缩版仍可用但无"不可关"的明文。
- F4 主体成立但有重要 nuance：对象管理 API 确已下线（C8/C9/C10 前段），但现行 API 新增请求级 `prompt_cache_options`（TTL 可控）且 Anthropic 端点顶层 cache_control 生效——若成稿写「Kimi 无任何缓存控制参数」则为误；若仅写「无缓存对象管理 API」则正确。
