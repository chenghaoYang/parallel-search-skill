## conflicts
- 关于 OAuth 版本要求的不同表述：早期文档（2024-11-05）将 OAuth 2.1 描述为参考标准，但没有明确 MUST 实现；最新规范（2026-07-28）明确要求授权服务器 MUST 实现 OAuth 2.1。这反映的是要求强化而非冲突。 | src: https://modelcontextprotocol.io/docs/2024-11-05/tutorials/security/authorization vs https://modelcontextprotocol.io/specification/draft/basic/authorization

## gaps
- 初始版本 2024-10-07 的授权具体特性（是否包含 OAuth 2.1 或仅基础支持）未能从官方文档明确确认
- Dynamic Client Registration 被标记为弃用的确切版本号（可能在 2025-06-18 或 2025-11-25）
- Steering Committee 是否正式成立的明确说法（文档提到 Core Maintainers 而非 Steering Committee）

## leads
- MCP 治理在 2025 年中期经历重大变化：从 Anthropic 单独维护转向开放社区模型（通过工作组），2025-12-09 又转移到 Agentic AI Foundation；需要了解各阶段的详细权力转移
- RFC 9207 issuer validation 在 2026-07-28 版本强化了安全性，体现了版本间的鉴权能力演进
