# r3-aaif-a2a-date
question: A2A（Agent2Agent Protocol）是否、以及确切在什么日期，作为 "hosted project"（而非 founding project）加入了 Linux Foundation 的 Agentic AI Foundation（AAIF）？请找一手官方来源（linuxfoundation.org 新闻稿、aaif.io 官方页面）核实精确日期和原句。
checked: https://aaif.io/blog/a2a-joins-aaif, https://aaif.io/projects, https://www.linuxfoundation.org/projects/agentic-ai-foundation/

## claims
- [C1] aaif.io/blog/a2a-joins-aaif 文章发布日期为 2026-08-17（August 17, 2026）| src: https://aaif.io/blog/a2a-joins-aaif | quote: "date: 2026-08-17" | type: official
- [C2] 官方博客确认"Agent2Agent (A2A), the open standard for inter-agent communication, is joining the Agentic AI Foundation (AAIF) as a hosted project" | src: https://aaif.io/blog/a2a-joins-aaif | quote: "is joining the Agentic AI Foundation (AAIF) as a hosted project" | type: official
- [C3] AAIF 官方项目页面（https://aaif.io/projects）列出 Agent2Agent (A2A) 为 hosted open source project | src: https://aaif.io/projects | quote: "an open protocol that enables AI agents to communicate, collaborate, and securely exchange information and tasks" | type: official

## conflicts
- None identified. The blog publication date (2026-08-17) and project listing are consistent.

## gaps
- 博客文章本身未明确说明 "加入生效日期" 是否与发布日期相同，还是提前或延后宣布。文章发布于 2026-08-17，但未找到是否该日期即为 A2A 正式加入生效的明确陈述。
- Linux Foundation 官方新闻稿或项目列表页面中未找到相关确认（linuxfoundation.org 上的相关 URL 返回 404）。

## leads
- AAIF 官方博客确认日期为 2026-08-17（August 17, 2026），与上一轮的"2026年8月"相符，精确到日期。
- 可在正文中确认使用"2026-08-17"或"2026年8月17日"，来自官方博客发布日期。
