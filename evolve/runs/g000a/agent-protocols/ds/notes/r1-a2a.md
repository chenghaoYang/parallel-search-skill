## conflicts
- key-concepts：“JSON-RPC 2.0 is used as the payload format for all requests and responses.”（https://a2a-protocol.org/latest/topics/key-concepts/）对规范三种绑定 JSONRPC/GRPC/HTTP+JSON（https://a2a-protocol.org/latest/specification/）。
- whats-new：v1 用 TASK_STATE_* 与 ROLE_*，v0.3 用 submitted/input-required 与 user/agent（https://a2a-protocol.org/latest/whats-new-v1/）。life-of-a-task 散文仍用 input-required、completed（https://a2a-protocol.org/latest/topics/life-of-a-task/）。llms.txt 写 SUBMITTED 无前缀（https://a2a-protocol.org/latest/llms.txt）。
- whats-new：“removed deprecated implicit/password flows”。规范仍列 implicit、password 并标 Deprecated（https://a2a-protocol.org/latest/specification/）。
- 鉴权字段：enterprise-ready 的 security，对规范 securitySchemes、securityRequirements 与句中 AgentCard.security。proto 路径 spec/a2a.proto 对 specification/a2a.proto。protocolVersion 例子 0.3/1.0，文档版本 1.0.0（https://a2a-protocol.org/latest/specification/）。
- 首页 TSC 写 IBM Research。GOVERNANCE.md 席位写 IBM。博客写已进入 Linux Foundation-directed AAIF。
