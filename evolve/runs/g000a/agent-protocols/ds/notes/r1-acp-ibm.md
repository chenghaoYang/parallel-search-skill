## conflicts
- 并入 vs 仍并列：“ACP is now part of A2A under the Linux Foundation!”（https://agentcommunicationprotocol.dev/introduction/welcome.md）对照 “Agent2Agent Protocol (A2A), launched by Google in April 2025, both aim to create a standard interface for agent-to-agent communication.”（https://agentcommunicationprotocol.dev/about/mcp-and-a2a.md）。公告 “previously powered by ACP, now uses A2A”（https://github.com/orgs/i-am-bee/discussions/5）。
- 鉴权： “Support for common authentication methods such as Basic Auth, Bearer tokens, and JWTs”（https://agentcommunicationprotocol.dev/core-concepts/production-grade.md）对 “security: []”（https://agentcommunicationprotocol.dev/spec/run-create.md）。
- 路径：lifecycle 正文 “run/{run_id}/cancel”（https://agentcommunicationprotocol.dev/core-concepts/agent-run-lifecycle.md）对 OpenAPI “/runs/{run_id}/cancel:”；会话 “/session/{session_id}:” 的参数是 “name: name”（https://agentcommunicationprotocol.dev/spec/openapi.yaml）。

## gaps
- 无 “Agent Client Protocol”。Zed 只是 IDE：“This method also works with other IDEs like VSCode, Zed, and Windsurf, etc.”（https://agentcommunicationprotocol.dev/integrations/cursor.md）。
- 无 Authorization header / securitySchemes（尾截断）。无 0.2.0 以外版本。servers 仅 http://localhost:8000。sessions-get.md 几乎空。
