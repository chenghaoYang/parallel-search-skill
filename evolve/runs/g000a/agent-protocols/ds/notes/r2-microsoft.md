## conflicts
- Agent card：AF 原句 "discoverable at `/.well-known/agent.json`"（https://learn.microsoft.com/en-us/agent-framework/hosting/self-hosting/a2a/dotnet）。Copilot Studio 原句 "endpoint + `/.well-known/agent.json`"（https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-agent-agent-to-agent）。Foundry 原句 "the default `.well-known/agent-card.json`"（https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/enable-agent-to-agent-endpoint）。
- 传输：Foundry "A2A v1.0 is JSONRPC-only" 且 "Streaming responses (server-sent events) aren't supported."（同上 Foundry）。AF "Both are supported"，HTTP+JSON 为 "Server-Sent Events for streaming."（同上 AF）。
- Copilot Studio MCP 同页既写 "Prompts: Predefined prompt templates"，又写 "currently supports MCP tools and resources."（https://learn.microsoft.com/en-us/microsoft-copilot-studio/agent-extend-action-mcp）。
