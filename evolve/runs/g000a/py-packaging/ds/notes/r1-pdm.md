# r1-pdm
question: PDM 官方文档里，项目元数据、锁文件（含是否支持 PEP 751 pylock.toml）、workspace、Python 版本管理、构建后端、环境、依赖组、私有源、CI 缓存、从其他工具导入，各自的字段名和命令是什么？
checked: https://pdm-project.org/en/latest/reference/pep621/, https://pdm-project.org/en/latest/usage/project/, https://pdm-project.org/en/latest/usage/lockfile/, https://pdm-project.org/en/latest/reference/configuration/, https://pdm-project.org/en/latest/reference/cli/, https://pdm-project.org/en/latest/reference/build/, https://backend.pdm-project.org/, https://pdm-project.org/en/latest/usage/workspace/, https://pdm-project.org/en/latest/usage/venv/, https://pdm-project.org/en/latest/usage/pep582/, https://pdm-project.org/en/latest/usage/dependency/, https://pdm-project.org/en/latest/usage/config/, https://pdm-project.org/en/latest/usage/advanced/, https://pdm-project.org/en/latest/dev/changelog/, https://pdm-project.org/

## claims
- [C1] D1：是 [project]（PEP 621，另引 PEP 631、PEP 639）。字段 version、project.dependencies、requires-python；可选组 [project.optional-dependencies]，命令 pdm install -G。动态版本用 dynamic=["version"] 与 [tool.pdm].version。 | src: https://pdm-project.org/en/latest/reference/pep621/ | quote: "metadata should be written under `[project]` table if not given explicitly." | type: official
- [C2] D1：库会写 name、version 与 [build-system]。[tool.pdm] distribution=true 视为库。默认构建后端名为 pdm-backend。 | src: https://pdm-project.org/en/latest/usage/project/ | quote: "there is a field `distribution` under the `[tool.pdm]` table. If it is set to true, PDM will treat the project as a library." | type: official
- [C3] D2：格式 pdm（默认文件 pdm.lock）与 pylock（默认文件 pylock.toml），默认格式 pdm。Added in 2.25.0，PEP 751 experimental。切换命令 pdm config lock.format pylock。 | src: https://pdm-project.org/en/latest/usage/lockfile/ | quote: "PDM supports two lock file formats: `pdm`(default file name is `pdm.lock`) and `pylock`(default file name is `pylock.toml`)." | type: official
- [C4] D2：写 pdm lock；pdm install 与 pdm add 也会创建 pdm.lock。读 pdm sync（不创建不更新）。路径 -L/--lockfile 或 PDM_LOCKFILE。原生格式字段 metadata.groups。--frozen-lockfile 不写锁；pdm lock --check 只检查。 | src: https://pdm-project.org/en/latest/usage/lockfile/ | quote: "You can specify another lock file with the `-L/--lockfile` option or the `PDM_LOCKFILE` environment variable" | type: official
- [C5] D2：导出命令与改格式分开。pdm export -o requirements.txt。PEP 751 导出原名 pdm export -f pylock -o pylock.toml（Added in 2.24.0）。CLI -f/--format 默认 requirements。 | src: https://pdm-project.org/en/latest/usage/lockfile/ | quote: "pdm export -f pylock -o pylock.toml" | type: official
- [C6] D3：Added in 2.28.0，Experimental。字段 [tool.pdm.workspace] members，值为路径或 glob。成员共享根环境与根锁。 | src: https://pdm-project.org/en/latest/usage/workspace/ | quote: "The `members` list accepts direct paths and glob patterns." | type: official
- [C7] D3：pdm add <path> 在目录含 pyproject.toml 时写入 members。pdm remove <path> 只删精确路径。须在根运行 pdm install、pdm lock、pdm sync、pdm outdated、pdm info。 | src: https://pdm-project.org/en/latest/usage/workspace/ | quote: "This removes the exact `packages/foo` entry from `[tool.pdm.workspace].members`" | type: official
- [C8] D4：解释器路径 .pdm-python，改用 pdm use；PDM_PYTHON 覆盖它。Added in 2.23.0：根目录 .python-version 或 PDM_PYTHON_VERSION。项目字段 requires-python。 | src: https://pdm-project.org/en/latest/usage/project/ | quote: "The interpreter path will be stored in `.pdm-python` and used by subsequent commands." | type: official
- [C9] D4：pdm python install <version>（Added in 2.13.0）；另有 --list、pdm python list、pdm python remove、pdm python install --min（Added in 2.16.0）。python.install_root 默认 ~/.local/share/pdm/python。CLI 别名 pdm py。 | src: https://pdm-project.org/en/latest/usage/project/ | quote: "pdm python install 3.9.8" | type: official
- [C10] D5：pdm-backend 配置为 requires=["pdm-backend"]、build-backend="pdm.backend"。同页还有 setuptools.build_meta、flit_core.buildapi、hatchling.build、maturin。poetry-core 因不读 PEP 621 而不被支持。 | src: https://pdm-project.org/en/latest/reference/build/ | quote: "poetry-core is not supported because it does not support reading PEP 621 metadata." | type: official
- [C11] D6：python.use_venv 默认 True，环境变量 PDM_USE_VENV。python.use_python_version 默认 True，环境变量 PDM_USE_PYTHON_VERSION。lock.format 默认 pdm，环境变量 PDM_LOCK_FORMAT。 | src: https://pdm-project.org/en/latest/reference/configuration/ | quote: "Use virtual environments when available" | type: official
- [C20] D6：PEP 582 已拒，建议改用 virtual environments。pdm config python.use_venv False 则用 __pypackages__。全局命令 pdm --pep582。 | src: https://pdm-project.org/en/latest/usage/pep582/ | quote: "We recommend using virtual environments instead." | type: official
- [C12] D6：venv.backend 默认 virtualenv，可选 venv、conda。venv.in_project 默认 True，路径 .venv。命令 pdm venv create|list|remove|activate，pdm use -f，pdm use --venv in-project。venv.location 默认 ~/.local/share/pdm/venvs。venv.with_pip 默认 False。 | src: https://pdm-project.org/en/latest/reference/configuration/ | quote: "Create virtualenv in `.venv` under project root" | type: official
- [C13] D7：现行写入表是 [dependency-groups]。pdm add -dG <group> <pkg>；仅 -d/--dev 进 dev 组。可选依赖是 pdm add -G 写入 [project.optional-dependencies]。同名不得两表并存。安装：pdm install、-G、-G:all、--prod、-d。 | src: https://pdm-project.org/en/latest/usage/dependency/ | quote: "dependencies will go to `dev` group under `[dependency-groups]` by default." | type: official
- [C14] D7：changelog v2.20.0（2024-10-31）支持 PEP 735，默认 dev 写入 [dependency-groups]。v2.22.4（2025-03-07）仍提到 tool.pdm.dev-dependencies 表存在时的分组。 | src: https://pdm-project.org/en/latest/dev/changelog/ | quote: "By default, dev dependencies will be written to [dependency-groups] table." | type: official
- [C15] D8：[[tool.pdm.source]] 字段 name、url、verify_ssl、username、password、type（index|find_links，默认 index）、include_packages、exclude_packages。name=pypi 替换默认索引。配置键 pypi.url 默认 https://pypi.org/simple，环境变量 PDM_PYPI_URL；另有 pypi.<name>.url。 | src: https://pdm-project.org/en/latest/usage/config/ | quote: "type : (Optional) index or find_links, default to index" | type: official
- [C16] D8：凭据用 URL 中 ${ENV}，或 pdm config pypi.<name>.username 与 pypi.<name>.password。keyring 服务名 pdm-pypi-<name>；pdm self add keyring。源顺序开关 [tool.pdm.resolution] respect-source-order。 | src: https://pdm-project.org/en/latest/usage/config/ | quote: "The service name will be `pdm-pypi-<name>` for an index" | type: official
- [C17] D9：cache_dir 默认 ~/.cache/pdm，环境变量 PDM_CACHE_DIR。install.cache 默认 False；pdm config install.cache on。缓存目录 $(pdm config cache_dir)/packages。install.cache_method 默认 symlink，另有 hardlink。命令 pdm cache clear|remove|list|info。 | src: https://pdm-project.org/en/latest/reference/configuration/ | quote: "The root directory of cached files" | type: official
- [C18] D9：CI 示例用 pdm-project/setup-pdm@v4 与 pdm sync -d -G testing。无用户时缓存目录可能权限失败，变通 export HOME=/tmp/home。应提交 pyproject.toml，建议提交 pdm.lock 与 pdm.toml，不要提交 .pdm-python。 | src: https://pdm-project.org/en/latest/usage/advanced/ | quote: "you might get permission errors when PDM tries to create its cache directory." | type: official
- [C19] D10：命令 pdm import。支持 Pipfile、Poetry 段、Flit 段、requirements.txt、setup.py。pdm init 或 pdm install 可自动探测。CLI：filename、-f/--format、-d/--dev、-G/--group。 | src: https://pdm-project.org/en/latest/usage/project/ | quote: "PDM provides `import` command so that you don't have to initialize the project manually" | type: official
