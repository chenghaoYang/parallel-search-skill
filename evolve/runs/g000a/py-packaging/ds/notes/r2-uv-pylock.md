# r2-uv-pylock
question: uv 的项目接口是否仍只认 uv.lock，pylock.toml 的读和写分别落在哪条命令上？同一页里 “future” 和现行 uv pip 命令是不是同时成立？
checked: https://docs.astral.sh/uv/concepts/projects/layout/, https://docs.astral.sh/uv/concepts/projects/sync/, https://docs.astral.sh/uv/concepts/projects/export/, https://github.com/astral-sh/uv/releases/tag/0.6.15

## claims
- [C1] layout 页脚 July 21, 2026：项目接口继续用 uv.lock，不改用 pylock.toml。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "Some of uv's functionality cannot be expressed in the pylock.toml format; as such, uv will continue to use the uv.lock format within the project interface." | type: official
- [C2] 同页：项目在 pyproject.toml 旁创建 uv.lock。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "uv creates a uv.lock file next to the pyproject.toml." | type: official
- [C3] 同页紧接两句：该锁由 uv sync 与 uv run 自动创建更新，也可由 uv lock 显式更新。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "The lockfile is automatically created and updated during uv invocations that use the project environment, i.e., uv sync and uv run. The lockfile may also be explicitly updated using uv lock." | type: official
- [C4] 同页：uv.lock 格式只属于 uv，其他工具不能用。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "The uv.lock format is specific to uv and not usable by other tools." | type: official
- [C5] 同页：从 uv.lock 写出 pylock.toml 的命令是 uv export -o pylock.toml。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "To export a uv.lock to the pylock.toml format, run: uv export -o pylock.toml" | type: official
- [C6] 同页：从 requirements 写出 pylock.toml 的命令是 uv pip compile requirements.in -o pylock.toml。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "To generate a pylock.toml file from a set of requirements, run: uv pip compile requirements.in -o pylock.toml" | type: official
- [C7] 同页：从 pylock.toml 安装的命令是 uv pip sync pylock.toml 或 uv pip install -r pylock.toml。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "To install from a pylock.toml file, run: uv pip sync pylock.toml or uv pip install -r pylock.toml" | type: official
- [C8] 同页概括支持范围：导出目标，以及 uv pip CLI。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "However, uv supports pylock.toml as an export target and in the uv pip CLI." | type: official
- [C9] 同页 future 原句：跨工具安装写成 in the future（与 C7 同页，见 conflicts）。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "pylock.toml is standardized and tool-agnostic, such that in the future, pylock.toml files generated by uv could be installed by other tools, and vice versa." | type: official
- [C10] sync 页脚 August 5, 2026：uv sync 与 uv lock 沿用已有 uv.lock 里的版本。 | src: https://docs.astral.sh/uv/concepts/projects/sync/ | quote: "With an existing uv.lock file, uv will prefer the previously locked versions of packages when running uv sync and uv lock." | type: official
- [C11] 同页：uv run 会先锁定并同步项目后再执行命令。 | src: https://docs.astral.sh/uv/concepts/projects/sync/ | quote: "For example, when uv run is used, the project is locked and synced before invoking the requested command." | type: official
- [C12] sync 页脚 August 5, 2026：可把 uv.lock 导出为 pylock.toml（PEP 751）等格式。 | src: https://docs.astral.sh/uv/concepts/projects/sync/ | quote: "If you need to integrate uv with other tools or workflows, you can export uv.lock to different formats including requirements.txt, pylock.toml (PEP 751), and CycloneDX SBOM." | type: official
- [C13] export 页脚 November 20, 2025：写出 pylock.toml 的示例命令是 uv export --format pylock.toml --output-file pylock.toml。 | src: https://docs.astral.sh/uv/concepts/projects/export/ | quote: "$ uv export --format pylock.toml --output-file pylock.toml" | type: official

- [C15] Release 0.6.15 称此为 pylock.toml 的 preliminary support（PEP 751）。 | src: https://github.com/astral-sh/uv/releases/tag/0.6.15 | quote: "This release includes preliminary support for the pylock.toml file format, as standardized in PEP 751." | type: official

## gaps
- layout、sync、export 全文都没有 uv lock、uv sync、uv run 读取 pylock.toml 的命令或参数，也没有“这些命令拒绝读取 pylock.toml”的否定原句。
- 发布页可见日期只有 “22 Apr 00:51”；年份不在这段可见文案里。年份只来自同节点 HTML datetime="2025-04-22T00:51:50Z"（已写入 C14）。
