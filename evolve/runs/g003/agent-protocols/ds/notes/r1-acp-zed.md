## conflicts
- v1 用 authenticate、session/load，prompt 响应结束回合（https://agentclientprotocol.com/protocol/v1/overview）。v2 用 auth/login、session/resume，且 authMethods 非空必须有 auth/logout（https://agentclientprotocol.com/protocol/v2/overview ，https://agentclientprotocol.com/protocol/v2/initialization）。
- v1 MCP stdio “MUST support”（https://agentclientprotocol.com/protocol/v1/session-setup）；v2 可省略（https://agentclientprotocol.com/protocol/v2/initialization）。introduction 写 “HTTP or WebSocket”（https://agentclientprotocol.com/get-started/introduction）；transports 仅 stdio 与 draft Streamable HTTP，batch 仅 v2（https://agentclientprotocol.com/protocol/v2/transports）。
- brand alt 为 “Agentic Client Protocol Logo”，正文仍是 Agent Client Protocol（https://agentclientprotocol.com/brand）。
