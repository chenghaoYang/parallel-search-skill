## conflicts

- 事件数：spec quote: "Thirty-one event types, in eight families" （https://docs.ag-ui.com/spec/1.0/basic/index.md）。concepts quote: "any of the 16 standardized event types" （https://docs.ag-ui.com/concepts/architecture.md）。README quote: "one of AG-UI's ~16 standard event types"。schema EventType 枚举为 31 项。不裁决概念页是否过时。
- 传输/严格性：concepts quote: "AG-UI doesn't mandate how events are delivered" 且 "Events don't need to match AG-UI's format exactly"。spec quote: "An implementation that speaks HTTP MUST support the SSE binding" 且架构页 "A producer MUST emit only what the schema defines" （https://docs.ag-ui.com/spec/1.0/architecture.md）。
- 能力：散文 quote: "the boolean fields exist to carry false explicitly." schema AgentCapabilities 描述 quote: "agents only declare what they support." ReasoningCapabilities.supported 仍是 boolean。
