## conflicts
- TTL 下界：Developer generateContent 指南（2026-09-11）写 "There are no minimum or maximum bounds on the TTL."（https://ai.google.dev/gemini-api/docs/generate-content/caching）。Agent Platform 概览（2026-09-22）写创建后最短 "1 minute"，且 "There isn't a maximum cache duration"（https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-overview）。未裁决。
- 最低 token：Developer implicit 表把 Gemini 3.8 Flash 与 3.1 Pro Preview 标为 4,096、2.5 标为 2,048（https://ai.google.dev/gemini-api/docs/generate-content/caching）。同日之后的 Agent Platform 表写 Gemini 3 族 4,096，但 "3.0 Flash Preview, 3.1 Pro Preview, 3.7 Flash, and 3.8 Flash (implicit caching only): 6,144 tokens"，Gemini 2 族 2,048（https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-overview）。
- 折扣比例版本差：2025-05-08 博客写 implicit "providing the same 75% token discount"，且把 2.5 Flash/Pro 最低降到 1024/2048（https://developers.googleblog.com/gemini-2-5-models-now-support-implicit-caching/）。2026-09-22 Vertex 概览写 implicit 与 2.5+ explicit 均为 90%，2.0 explicit 为 75%。Developer 现行指南只写 implicit "no cost saving guarantee"、explicit "cost saving guarantee"，不写百分比。
- 存储费是否覆盖 implicit：Vertex 概览写 "There are no storage costs for implicit caching."，定价表标题是 "Context Cache Storage price for Explicit Caching"。Developer 定价页（2026-09-23）Context caching price 行内含 storage price，且全文无 implicit/explicit；计费 FAQ 列 "Cached token storage duration"（https://ai.google.dev/gemini-api/docs/billing）也不拆两套。未裁决 Developer implicit 命中是否另收存储费。

## gaps
- Developer 现行 caching 页未写 implicit 的 TTL 或失效 API；只写相似前缀与短时间。changelog 抽取全文无 "implicit"，起点只见于 2025-05-08 博客，不在 changelog。
- Developer generateContent 页未写设置 cachedContent 后，未放入 cache 的后缀能否再吃 implicit。Vertex 写两者会叠加（C31）。
- Developer explicit 作用域只见到 name=cachedContents/{id} 且绑定 model；未写是按 API key 还是按项目。
- ZDR 页（https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/zero-data-retention）描述的是 in-memory Customer Data 缓存、24-hour TTL、项目级 disableCache；抽取文本无 "implicit"。概览让读者用该节关掉 implicit，但是否同一开关，ZDR 页自身未写明。不要把 24h 当成 context cache TTL。
- 定价页不标明 Context caching price 行是只计 explicit 引用、只计 implicit 命中，还是两者共用。
