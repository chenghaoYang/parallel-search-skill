## conflicts
- Claude Opus 4.7 每检查点最小 token：Anthropic 写 "2,048 tokens for Claude Mythos Preview and Claude Opus 4.7"，并写 "These minimums apply on every platform where each model is available."（https://platform.claude.com/docs/en/build-with-claude/prompt-caching）；同页又写 Bedrock 以 Bedrock 文档的 per-model minimums 为准。Bedrock 支持表把 Claude Opus 4.7 的 Minimum number of tokens per cache checkpoint 列为 4,096（https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html）。未裁决。
- GPT-5.6 的 prompt_cache_key：Azure 写 "This parameter improves cache matching for related requests."（https://learn.microsoft.com/en-us/azure/foundry/openai/how-to/prompt-caching）；OpenAI 写 "On GPT-5.6 and later, OpenAI handles cache routing automatically; the key is not needed to optimize caching."（https://developers.openai.com/api/docs/guides/prompt-caching）。未裁决。
- 「自动/隐式」在 Bedrock 上不是同一开关：Anthropic 写 legacy Bedrock（Opus 4.6 及更早）对顶层 cache_control 返回 400（见 C15）；Bedrock 写 "Implicit Prompt Caching automatically attempts to reuse eligible prompt prefixes without requiring cache controls in your request." 且 "doesn't guarantee a cache hit"（https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html）。可能是两套机制，未把其中一方判错。
