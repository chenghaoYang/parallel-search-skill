# taxonomy 网格 v0

分类轴：**这个工具默认锁住并安装的是哪一种制品，以及它拥不拥有「解释器」和「项目元数据」。**

这条轴要解释矩阵里的大部分差异：锁文件长得像不像 `pylock.toml`、有没有 `[project]`、Python 是工具装的还是环境里的一个包、构建后端是不是 PyPI 那套 PEP 517。解释不了再换轴。

## 家族

| 家族 | 实体 | 为什么是一类 |
|---|---|---|
| A. PyPI 安装器 | pip | 把 wheel/sdist 装进已有环境。项目表、解释器、锁文件长期是别的标准或外挂在补。 |
| B. PyPI 项目管理器 | Poetry、PDM、uv | 读项目清单、解析 PyPI、写锁、管虚拟环境。族内再按「元数据是不是 PEP 621」和「会不会自己装 CPython」分开。 |
| C. conda 前缀 | pixi、conda | 锁/解的是前缀里的二进制包（channel），Python 只是其中一个包。PyPI 是附加通道，不是默认世界。 |

预期但 R1 不成行的变体（工人只许写进 leads）：pip-tools、hatch、rye、conda-lock。它们只有在会改变「新项目选谁」时才升格成行。

## 维度

| ID | 维度 | 这一列回答什么问题 |
|---|---|---|
| D1 | 锁文件 | 锁的文件名叫什么、是不是 PEP 751 `pylock.toml`、生成和安装分别从哪一版开始、锁里有没有 hash？ |
| D2 | 项目表 | 依赖和项目元数据写在 `[project]` / `[dependency-groups]`，还是工具私有表？ |
| D3 | workspace | 有没有 monorepo/workspace？成员列表的字段名是什么？ |
| D4 | Python 版本 | 谁安装 CPython？版本约束写在 `requires-python`、`.python-version`，还是写成环境里的 `python` 包？ |
| D5 | 构建后端 | `build-system` 默认的 `build-backend` 字符串是什么？工具自己是不是后端？ |
| D6 | 环境形态 | 装进当前解释器、项目旁的 venv，还是 conda/pixi 前缀？默认路径？ |
| D7 | 迁移 | 官方从 pip / Poetry / conda / PDM 迁入的命令或文档入口是什么？ |
| D8 | CI 缓存 | 官方点名要缓存的目录或环境变量是什么？ |
| D9 | 私有源 | 私有 index / channel 写在哪个文件、哪个字段？凭据放哪？ |
| D10 | 依赖分组 | dev / 可选依赖的字段名（group、extra、dependency-group）是什么？ |
