# brief

读者：要选型或读新闻的工程师。几分钟内要能说出每条协议接哪两端、和别的协议是互补还是同名异物，再按表查鉴权、传输、版本和治理。

截至：调研日 2026-09-24。成稿只写笔记里有原句的事实。

## 成稿要建立的认知

1. MCP、A2A、AG-UI，以及两个都缩写成 ACP 的规范，各自管什么、不管什么。
2. 它们不是同一层的替代品。分类轴是「线上两端的角色」。
3. 用户点名的疑点有明确结论：两个 ACP 是否同一件事；MCP 的 SSE 传输是否已废弃。
4. OpenAI、Anthropic、Google、微软各自官方支持哪些、有没有自家变体（变体要写原名）。
5. 鉴权、现行版本、谁在治理、怎么选。选型规则必须能从分类轴推出来。

## 范围内

- 上述协议的现行规范：接线两端、能力面、发现、传输、鉴权、状态归属、版本与弃用、治理与许可、与相邻协议的官方关系。
- 四家大厂的官方支持声明和自家协议/接口变体（原名）。
- 读者会和这四条搞混的相邻规范（由 scout 点名后再决定是否入网格）。

## 范围外

- 某个 SDK 的安装步骤、示例代码、价格。
- 厂商模型能力（函数调用、computer use）本身，除非它被官方当成一条可互操作协议或某协议的变体。
- 评测榜、市场占有率、未点名的创业公司集成清单。

## 种子词

MCP (Model Context Protocol)；A2A (Agent2Agent)；ACP；AG-UI。

- 网上说的 ACP 有两个：IBM Agent Communication Protocol，和 Zed Agent Client Protocol。是不是一回事？
- 有人说 MCP 的 SSE 传输已经废弃。规范现在怎么写？
- 四家大厂各支持哪些，有没有自家变体？
- 鉴权、版本、谁在治理、怎么选？
