## conflicts
- 规范站头部标 "Latest Released Version 1.0.0"，但 GitHub repo 最新 release 为 v1.0.1（published 2026-05-28，spec bug fixes）。两边同为官方：站点 https://a2a-protocol.org/latest/specification/ vs https://api.github.com/repos/a2aproject/A2A/releases/latest。可能只是文档版本标签滞后于 patch release。
- 教程页 what-is-a2a 的时序图仍写旧路径 "/.well-known/agent-card" 和旧方法名 sendMessage/sendMessageStream，而规范 §8.2/§9 用 "/.well-known/agent-card.json" 与 PascalCase SendMessage。同站新旧表述并存。
