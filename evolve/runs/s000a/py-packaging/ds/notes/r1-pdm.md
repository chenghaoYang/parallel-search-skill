# r1-pdm
question: PDM 官方文档里，锁文件（含是否接 PEP 751）、项目元数据、workspace、Python 版本、构建后端、私有源、CI 缓存、从 Poetry/pipenv/flit 迁移，各自的字段和命令是什么？
checked: https://pdm-project.org/latest/, https://pdm-project.org/latest/usage/lockfile/, https://pdm-project.org/latest/usage/project/, https://pdm-project.org/latest/usage/dependency/, https://pdm-project.org/latest/reference/pep621/, https://pdm-project.org/latest/usage/config/, https://pdm-project.org/latest/reference/configuration/, https://pdm-project.org/latest/reference/build/, https://pdm-project.org/en/latest/usage/workspace/, https://pdm-project.org/en/latest/usage/advanced/, https://github.com/pdm-project/setup-pdm, https://pdm-project.org/latest/reference/cli/

## claims
- [C1] lock：默认锁文件名 `pdm.lock`；`pdm lock` 生成/覆盖，`pdm install`、`pdm add` 也会自动创建。 | src: https://pdm-project.org/latest/usage/lockfile/ | quote: "PDM synchronizes dependencies using a locked resolution, normally stored in `pdm.lock`." | type: official
- [C2] lock：支持两种锁格式 `pdm`（默认，文件名 `pdm.lock`）与 `pylock`（文件名 `pylock.toml`）；2.25.0 起实验性支持 PEP 751，`pdm config lock.format pylock` 切换，官方称未来会成为默认。 | src: https://pdm-project.org/latest/usage/lockfile/ | quote: "PDM supports two lock file formats: `pdm`(default file name is `pdm.lock`) and `pylock`(default file name is `pylock.toml`). The default format is `pdm`." | type: official
- [C3] lock：2.24.0 起 `pdm export -f pylock -o pylock.toml` 导出 PEP 751 兼容格式；export 另支持 requirements.txt（`-f` 可选值 `requirements`/`pylock.toml`）。 | src: https://pdm-project.org/latest/usage/lockfile/ | quote: "Additionally, PDM supports exporting to `pylock.toml` format as defined by PEP 751" | type: official
- [C4] lock：可用 `-L/--lockfile` 选项或 `PDM_LOCKFILE` 环境变量指定其他锁文件；`pdm lock --check` 检查新鲜度，`--refresh` 刷新哈希，`--frozen-lockfile` 只读不写。 | src: https://pdm-project.org/latest/usage/lockfile/ | quote: "You can specify another lock file with the `-L/--lockfile` option or the `PDM_LOCKFILE` environment variable" | type: official
- [C5] meta：项目元数据放 `pyproject.toml` 的 `[project]` 表，遵循 PEP 621/631/639；`project.dependencies` 用 PEP 508 字符串，`[project.optional-dependencies]` 管 extras。 | src: https://pdm-project.org/latest/reference/pep621/ | quote: "The project metadata are stored in the `pyproject.toml`. The specifications are defined by PEP 621, PEP 631 and PEP 639." | type: official
- [C6] meta：`[tool.pdm]` 管 PDM 专属设置，如 `distribution`（当 library 处理）、动态 `version = { source = "file", path = ... }`、`ignore_package_warnings`；子表含 `[tool.pdm.resolution]`、`[tool.pdm.options]`、`[tool.pdm.workspace]`、`[[tool.pdm.source]]`。 | src: https://pdm-project.org/latest/usage/project/ | quote: "In `pyproject.toml`, there is a field `distribution` under the `[tool.pdm]` table. If it is set to true, PDM will treat the project as a library." | type: official
- [C7] meta：dev 依赖组写 `[dependency-groups]`（PEP 735 表名），`pdm add -dG test pytest` 生成 `[dependency-groups] test = ["pytest"]`；不进分发元数据，文档未用 `[tool.pdm.dev-dependencies]`。 | src: https://pdm-project.org/latest/usage/dependency/ | quote: "Unlike `optional-dependencies`, they won't appear in the package distribution metadata such as `PKG-INFO` or `METADATA`" | type: official
- [C8] workspace：2.28.0 起有实验性 workspace，根 `pyproject.toml` 配 `[tool.pdm.workspace] members = ["packages/foo", ...]`（支持 glob），成员作为根的隐式可编辑依赖、共享根环境与锁文件；`pdm install`/`lock`/`sync`/`outdated`/`info` 须在根运行。 | src: https://pdm-project.org/en/latest/usage/workspace/ | quote: "Workspace members are configured in the root project's `pyproject.toml`" | type: official
- [C9] workspace：另有传统 monorepo 方案——子包以 `-e file:///${PROJECT_ROOT}/packages/foo` 写进 `[dependency-groups]` dev，根上单一 `pdm.lock` 统一锁定。 | src: https://pdm-project.org/en/latest/usage/advanced/ | quote: "you can have multiple sub-packages within a single project, each with its own `pyproject.toml` file. And you can create only one `pdm.lock` file to lock all dependencies." | type: official
- [C10] pyver：`pdm use` 选择/更换解释器，路径存 `.pdm-python`，可被 `PDM_PYTHON` 环境变量覆盖；找不到时 PDM 会自动安装（CLI 原文 "If not found, PDM will try to install one."）。 | src: https://pdm-project.org/latest/usage/project/ | quote: "The interpreter path will be stored in `.pdm-python` and used by subsequent commands. You can also change it later with `pdm use`." | type: official
- [C11] pyver：2.13.0 起 `pdm python install <ver>`（如 `3.9.8`、`3.13t`）从 indygreg/python-build-standalone 下载解释器，装到 `python.install_root`（默认 `~/.local/share/pdm/python`）；另有 `pdm python list/remove/link/find`。 | src: https://pdm-project.org/latest/usage/project/ | quote: "PDM supports installing additional Python interpreters from @indygreg's python-build-standalone with the `pdm python install` command." | type: official
- [C12] pyver：2.23.0 起认项目根 `.python-version` 文件或 `PDM_PYTHON_VERSION`；解释器查找源由 `python.providers` 配置，默认来源 `venv`/`path`/`pyenv`/`rye`/`asdf`/`winreg`。 | src: https://pdm-project.org/latest/usage/config/ | quote: "By default, PDM will try to find Python interpreters in the following sources: `venv`... `path`... `pyenv`... `rye`... `asdf`... `winreg`" | type: official
- [C13] backend：PDM 是 PEP 517 构建前端，`pdm init` 让用户选后端，不强制；初始支持列表：pdm-backend、setuptools、flit、hatchling、maturin。 | src: https://pdm-project.org/latest/reference/build/ | quote: "Unlike other package managers, PDM does not force you to use a specific build backend." | type: official
- [C14] backend：默认后端是 `pdm-backend`（`requires = ["pdm-backend"]`, `build-backend = "pdm.backend"`），需 Python>=3.7；poetry-core 因不读 PEP 621 元数据而不支持。 | src: https://pdm-project.org/latest/usage/project/ | quote: "the default backend `pdm-backend` only works on Python 3.7+" | type: official
- [C15] index：私有源用 `[[tool.pdm.source]]` 表，键原名 `name`/`url`/`verify_ssl`/`username`/`password`/`type`（`index` 或 `find_links`）；name 设为 `pypi` 会替换默认 PyPI；也可用 config 的 `pypi.url`、`pypi.<name>.url` 等。 | src: https://pdm-project.org/latest/usage/config/ | quote: "The available configuration options are: `url`... `verify_ssl`... `username`... `password`... `type`: (Optional) index or find_links, default to index" | type: official
- [C16] index：`include_packages`/`exclude_packages`（glob）把包绑定到指定源；`[tool.pdm.resolution] respect-source-order = true` 按源顺序查找；URL 支持 `${ENV_VAR}` 凭证展开，keyring 服务名 `pdm-pypi-<name>`。 | src: https://pdm-project.org/latest/usage/config/ | quote: "you can bind packages to specific sources with `include_packages` and `exclude_packages` config under `tool.pdm.source` table." | type: official
- [C17] cicache：`cache_dir` 默认 `~/.cache/pdm`，env `PDM_CACHE_DIR`；`pdm config install.cache on` 启用集中安装缓存（位于 `$(pdm config cache_dir)/packages`，`install.cache_method` = symlink/hardlink）；`pdm cache info/clear/remove/list`；`--no-cache`/`PDM_NO_CACHE`。 | src: https://pdm-project.org/latest/reference/configuration/ | quote: "`cache_dir` | The root directory of cached files | `~/.cache/pdm` | No | `PDM_CACHE_DIR`" | type: official
- [C18] cicache：CI 官方推荐 GitHub Action `pdm-project/setup-pdm@v4`（无需 setup-python）；其 `cache: true` 开缓存、`cache-dependency-path` 默认 `pdm.lock` 作缓存键；CI 无 HOME 时建议 `export HOME=/tmp/home` 避免缓存目录权限错。 | src: https://github.com/pdm-project/setup-pdm | quote: "The default path to calculate the cache key is `./pdm.lock`, you can change it by setting the `cache-dependency-path` input." | type: official
- [C19] migrate：`pdm import` 支持 5 种来源（Pipfile、Poetry 的 pyproject 段、Flit 的 pyproject 段、pip 的 requirements.txt、setuptools setup.py）；`pdm init`/`pdm install` 可自动检测可导入文件。 | src: https://pdm-project.org/latest/usage/project/ | quote: "it now supports: 1. Pipenv's `Pipfile` 2. Poetry's section in `pyproject.toml` 3. Flit's section in `pyproject.toml` 4. `requirements.txt` format used by pip 5. setuptools `setup.py`" | type: official
- [C20] migrate：`pdm import` 选项：`-f/--format` 显式指定格式、`-d/--dev` 导入为 dev 依赖、`-G/--group` 指定目标组；setup.py 转换会执行文件，需环境内装有 setuptools。 | src: https://pdm-project.org/latest/reference/cli/ | quote: "- `-f`, `--format`: Specify the file format explicitly" | type: official

## conflicts
- PDM 自身所需 Python 版本说法不一：首页 "PDM requires Python 3.10+ to be installed"（https://pdm-project.org/latest/）；同页下文 install-pdm.py 段 "PDM requires python version 3.9 or higher"；advanced 页 "PDM can't be installed on Python < 3.7"（https://pdm-project.org/en/latest/usage/advanced/）；setup-pdm README "PDM requires >=3.8"（https://github.com/pdm-project/setup-pdm）。文档未裁决，后两处疑似过时。
- `[dependency-groups]` 是文档现行表名；但页面提示 "For backward-compatibility, if only `-d` or `--dev` is specified, dependencies will go to `dev` group"——未说明旧 `[tool.pdm.dev-dependencies]` 写法的现状，非严格冲突，记录在 gaps。

## gaps
- `pdm import -f` 的枚举取值（是否含 `poetry`/`pipenv`/`flit`/`requirements`/`setuppy`/`pylock` 等字面值）CLI 页未列，只说 "Specify the file format explicitly"（https://pdm-project.org/latest/reference/cli/）。
- 未见 `pdm import`/`pdm lock` 直接读取/导入已有 `pylock.toml` 的说明（只看到 export 与 lock.format 写入侧）。
- 旧 `[tool.pdm.dev-dependencies]` 表名是否仍被读取/自动迁移，文档未提（查过 usage/dependency、reference/pep621）。
- import 来源列表无 hatch；setup-pdm 的 `cache: true` 具体缓存哪几个目录（wheel cache 还是 `install.cache` 包缓存）README 只说 "Cache PDM installation"。

## leads
- `pdm fix` 命令："Fix the project problems according to the latest version of PDM"（reference/cli）。
- `use_uv` 配置项（默认 False）可让 PDM 用 uv 做解析与安装，workspace 时会生成临时 `[tool.uv.workspace]` 元数据。
- `pdm lock` 的 Lock Target 选项 `--python`/`--platform`/`--implementation`/`--append` 可按目标锁（usage/lock-targets 页，未打开）。
- 官网首页特性列表自称 "PEP 621 project metadata"，可佐证"从一开始用 PEP 621"的说法方向。
