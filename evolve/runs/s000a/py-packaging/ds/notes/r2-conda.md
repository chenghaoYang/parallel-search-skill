## conflicts
- pixi 官方页（C28/C29）把 Conda 标为无内置 lockfiles；docs.conda.io 称 26.5 起原生支持 conda-lock.yaml/pixi.lock（C1/C2）。两边都未限定版本/插件前提，直接打架，不裁决。
- docs.conda.io 说 "natively"（C2），conda-lockfiles README 说须装插件进 base（C5）。"原生"是否含预装插件，文档口径不一，不裁决。
- pixi 首页抓取提示 "You're not viewing the latest version"，表行内容仍含 Lockfiles 字样，但与 /latest/ 是否逐字一致未二次核对。

## gaps
- conda 官方文档无 `conda lock`/`conda-lock` 子命令；锁文件读写全部走 `conda export`/`conda create --file`+conda-lockfiles 插件（已开 https://github.com/conda/conda-lockfiles 确认）。
- conda 文档无专门 "CI 缓存" 章节；可写的就是缓存 pkgs_dirs/CONDA_PKGS_DIRS 目录（C21/C22）。setup-miniconda 未展开。
- 文档内链 https://conda-incubator.github.io/conda-lockfiles/getting-started/ 已 404；仓库现位于 github.com/conda/conda-lockfiles。
