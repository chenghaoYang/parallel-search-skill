## conflicts
- 日期小矛盾：公告说 BeeAI「Later that month」（即 2025-03）捐给 LF（src: discussions/5, quote: "Later that month, the BeeAI project—and with it, ACP—was donated to the Linux Foundation"）；LF 官方新闻稿日期为 2025-04-29（src: linuxfoundation.org press URL above, quote: "SAN FRANCISCO, Calif., April 29, 2025"）。可能是宣布 vs 正式 inducted 之差。
- 文档内部新旧并存：about/mcp-and-a2a 仍把 ACP 当独立在营协议列「Advantages of ACP over A2A」（quote: "Open Governance: Managed through the Linux Foundation." 等对比项），与 welcome 页 banner「ACP is now part of A2A」矛盾——比较页未随合并更新。

## gaps
- 「ACP = Zed 的 Agent Client Protocol 吗」IBM 侧答案：官方 17 个文档页（llms.txt 全索引）全文 grep 无任何 "Agent Client Protocol" / "client protocol" 字样——IBM/BeeAI 官方未提及另一同名缩写协议；无原句可摘故记此。从 IBM 侧只能确认：其 ACP 全名是 "Agent Communication Protocol"、范围是 agent-to-agent REST 协议，与「Agent Client Protocol」全名和范围（客户端↔agent）均不同。
- ACP→A2A 迁移指南现址不明：公告链接 https://github.com/i-am-bee/beeai-platform/blob/main/docs/community-and-support/acp-a2a-migration-guide.mdx 已 404（仓库改名 agentstack）；agentstack.beeai.dev llms.txt grep 无 acp/migration 页。
- spec 0.2.0 之前是否有更早 spec 版本、0.2.0 发布日期：未查（git tag/历史未取）。
- 「自何时起归档/合并」精确到 commit 的时间线未核对。
