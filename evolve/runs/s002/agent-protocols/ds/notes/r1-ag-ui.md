- [C2] 模型：应用发一个 RunAgentInput，agent 回一条有序类型化事件流 | src: https://docs.ag-ui.com/spec/1.0 | quote: "one request in, one ordered stream of typed events out, carrying everything the user sees of the agent" | type: official

## conflicts
- README（0.x 时代描述）说 "~16 standard event types"，而 spec 1.0 schema.json 的 EventType enum 列 31 个值。README 原文："emit events *compatible* with one of AG-UI's ~16 standard event types"（https://github.com/ag-ui-protocol/ag-ui）vs schema（https://docs.ag-ui.com/spec/1.0/schema.json）。README 未随 1.0 更新，以 schema 为准但两边都是官方域名内容。

## gaps
- 规范未固定 agent endpoint 路径（示例用 POST /agent）；capabilities 的获取端点刻意未定义（设计如此，见 C15）。
- spec 1.0 的发布日期未在页面上标注；只看到 1.0 vs 0.x 的 changelog。
- WebSocket 传输只有 "custom transport" 一句话，无官方绑定细则。
