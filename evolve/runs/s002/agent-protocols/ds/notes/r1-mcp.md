## conflicts
- 「MCP 的 SSE 已废弃」需拆开：作为**独立传输**的 HTTP+SSE（2024-11-05 双端点方案）确已 Deprecated（2025-03-26 起，registry 原句 "Deprecated in `2025-03-26`"）；但 SSE 作为**格式**仍是现行 Streamable HTTP 的合法且必备响应类型——"the client MUST support both"（application/json 与 text/event-stream）。笼统说「SSE 已废弃」与现行 spec 冲突；准确说法是「HTTP+SSE transport 已废弃，SSE response stream 保留」。

## gaps
- 官方规范/治理页未见与 A2A、ACP、AG-UI 等具名 agent 协议的直接对比表述（查过 spec index、architecture、governance、agents WG、AAIF 博客，均未点名）。
- HTTP+SSE 的最终 Removed 时间未定：registry 写 "Three months after SEP-2596 reaches Final"，SEP-2596 当前状态未单独核实。
- 2024-11-05 版 HTTP+SSE 原始定义未直接抓取（deprecated registry 有链接 /specification/2024-11-05/basic/transports#http-with-sse）。

## leads
- 官方路线图方向：Tasks extension（SEP-2663，长任务异步执行）与可能的 Agents Extension 是 MCP 向 agentic 场景扩展的官方通道（agents WG charter，2026-08-04 初版）。
- AAIF 创始项目为 MCP（Anthropic）、goose（Block）、AGENTS.md（OpenAI）——分层对比时可注意 AGENTS.md 与 MCP 同基金会并列。
- 2026-07-28 为无状态大改版：删 ping/logging/setLevel、initialize 握手、session；list 结果要求 ttlMs/cacheScope 可缓存——若主文档按旧版（2025-11-25 及更早）描述需注意差异。
