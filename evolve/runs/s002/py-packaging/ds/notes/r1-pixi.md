## claims
- [C1] 锁文件原名 `pixi.lock`，由 pixi 自动生成、不应手改，随清单同步更新。docs 为 latest 版（对应 pixi 0.81.x，2026-09）。 | src: https://pixi.prefix.dev/latest/workspace/lock_file/ | quote: "Pixi - like many other modern package managers - has native support for lock files. This file is named `pixi.lock`." | type: official
- [C2] pixi.lock 结构分 environments（channels + 每平台 `- conda: <url>` 包引用）和 packages 去重清单（`kind: conda|pypi`, name, version, build, sha256, md5, depends 等）；文件头有版本号字段。 | src: https://pixi.prefix.dev/latest/workspace/lock_file/ | quote: "The Pixi lock file is structured into two parts." … "The lock file also has a version number … `version: 6`" | type: official
- [C3] 锁文件向后兼容不向前兼容："Pixi is backward compatible with the lock file, but not forward compatible." | src: https://pixi.prefix.dev/latest/workspace/lock_file/ | quote: "Pixi is backward compatible with the lock file, but not forward compatible." | type: official
- [C4] pixi 0.68.0（2026-05-07）把锁文件格式升到 v7（可复现源码包构建、更少 churn、无绝对路径）。 | src: https://github.com/prefix-dev/pixi/blob/main/CHANGELOG.md | quote: "[0.68.0] - 2026-05-07 … This release bump the lock file version to v7." | type: official
- [C5] 清单文件原名 `pixi.toml`，官方称 "the workspace manifest"。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "The `pixi.toml` is the workspace manifest, also known as the Pixi workspace configuration file." | type: official
- [C6] `pyproject.toml` 也可作清单：表名前缀 `tool.pixi`，如 `[tool.pixi.workspace]`；发现优先级 pixi.toml > pyproject.toml。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "We also support the `pyproject.toml` file. … you need to prepend the tables with `tool.pixi` … the `[workspace]` table becomes `[tool.pixi.workspace]`." | type: official
- [C7] 工作区表名 `[workspace]`，最小必填 `channels`、`platforms`、`name`（name 缺省取目录名）。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "The minimally required information in the `workspace` table is: `[workspace] channels = ["conda-forge"] name = "project-name" platforms = ["linux-64"]`" | type: official
- [C8] conda 来源键名：`channels`（在 `[workspace]`），支持 anaconda.org 短名、`file:///` 绝对路径、私有 URL；私有 prefix.dev/Quetz 用带主机名 URL。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "To access private or public channels on prefix.dev or Quetz use the url including the hostname: `channels = ["conda-forge", "https://repo.prefix.dev/channel-name"]`" | type: official
- [C9] PyPI 依赖表原名 `[pypi-dependencies]`（pyproject 中为 `[tool.pixi.pypi-dependencies]`），解析由内置 uv 完成且计入锁文件。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "We use `uv` … We integrate uv as a library, so we use the uv resolver … The uv resolution is included in the lock file directly." | type: official
- [C10] PyPI 索引配置在 `[pypi-options]`（另有 `[workspace.pypi-options]`、`[feature.<name>.pypi-options]`）：键 `index-url`（默认 `https://pypi.org/simple`，每环境仅一个）、`extra-index-urls`、`find-links`、`index-strategy`、`no-build`、`no-binary`、`no-build-isolation`、`prerelease-mode`、`skip-wheel-filename-check`。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "`index-url`: replaces the main index url. If this is not set the default index used is `https://pypi.org/simple`. **Only one** `index-url` can be defined per environment." | type: official
- [C11] 单个 PyPI 包可用 `index` 字段指向自定义索引。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "The index parameter allows you to specify the URL of a custom package index … `torch = { version = "*", index = "https://download.pytorch.org/whl/cu118" }`" | type: official
- [C12] Python 本身是普通 conda 依赖，写在 `[dependencies]`，用 conda version spec 钉版本（`python = "3.11.*"` / `pixi add python=3.8`）；锁文件中 python 条目为 `kind: conda`。 | src: https://pixi.prefix.dev/latest/reference/pixi_manifest/ | quote: "[dependencies] python = \">3.9,<=3.11\"" … (lock: `- kind: conda / name: python / version: 3.12.2`) | type: official
- [C13] pyproject.toml 中 PEP 621 `requires-python` 会被 pixi 读取并自动转成 conda `python` 依赖。 | src: https://pixi.prefix.dev/latest/python/pyproject_toml/ | quote: "The `pyproject.toml` file supports the `requires-python` field. Pixi understands that field and automatically adds the version to the dependencies." | type: official
- [C14] 构建系统原名 pixi-build（预览特性，需 `preview = ["pixi-build"]`）；后端在 `[package.build]`/`[package.build.backend]` 以 conda 包形式指定：`pixi-build-cmake`、`pixi-build-python`、`pixi-build-rattler-build`、`pixi-build-ros`、`pixi-build-r`、`pixi-build-rust`、`pixi-build-mojo`。 | src: https://pixi.prefix.dev/latest/build/backends/ | quote: "Install a certain build backend by adding it to the `package.build` section … `[package.build.backend] channels = ["https://prefix.dev/conda-forge"] name = "pixi-build-python" version = "0.*"`" | type: official
- [C15] 从 conda 迁移：`pixi init --import environment.yml`（`--import/-i <ENVIRONMENT_FILE>`），或已有 workspace 内 `pixi import --format=conda-env environment.yml`；导入格式支持 `conda-env` 与 `pypi-txt` 两种。 | src: https://pixi.prefix.dev/latest/reference/cli/pixi/init/ | quote: "`--import (-i) <ENVIRONMENT_FILE>` Environment.yml file to bootstrap the workspace … `pixi init --import environment.yml`" | type: official
- [C16] 官方 CI action 原名 `prefix-dev/setup-pixi`（例中 v0.10.0）；缓存输入 `cache`（有 pixi.lock 时默认开启，按 lockfile 哈希缓存 .pixi 环境）、`cache-key`、`global-cache`、`global-cache-key`、`cache-write`；`environments` 输入可装多环境；`locked`/`frozen` 控制 `pixi install` 行为。 | src: https://pixi.prefix.dev/latest/integration/ci/github_actions/ | quote: "By default, project environment caching is enabled if a `pixi.lock` file is present. It will then use the `pixi.lock` file to generate a hash of the environment and cache it." | type: official
- [C17] 缓存目录环境变量：`PIXI_CACHE_DIR`（缺省回落 `RATTLER_CACHE_DIR` → `$XDG_CACHE_HOME/pixi` → rattler 默认）；config.toml `[cache]` 表支持 `root` 及每类缓存键 `conda-packages`、`repodata`、`pypi-wheels`、`pypi-mapping`、`exec-environments`、`build-tool-environments`、`detached-environments`、`netfs-redirect`，各有 `PIXI_CACHE_<KIND>_DIR` 对应变量。 | src: https://pixi.prefix.dev/latest/reference/pixi_configuration/ | quote: "Override for the cache root. Equivalent to setting PIXI_CACHE_DIR. … Every `[cache]` field can be overridden by an environment variable." | type: official
- [C18] 私有 channel 认证原名 `pixi auth login <HOST>`（OAuth/OIDC 默认，支持 `--token` Bearer、`--conda-token`、`--username/--password`、S3 参数）；凭据存系统 keychain，回落 `~/.rattler/credentials.json`，可用 `RATTLER_AUTH_FILE` 覆盖；CI 中 setup-pixi 用 `auth-host`/`auth-token`/`auth-conda-token`/`persist-credentials`。 | src: https://pixi.prefix.dev/latest/deployment/authentication/ | quote: "The simplest way to authenticate against prefix.dev is: `pixi auth login prefix.dev`" | type: official
- [C19] 私有 PyPI 认证：keyring（`--pypi-keyring-provider subprocess|disabled`）或 `.netrc`；清单里写 `[pypi-options] index-url = "https://your_username@custom-registry.com/simple"`。 | src: https://pixi.prefix.dev/latest/deployment/authentication/ | quote: "Currently, we support the following methods for authenticating against PyPI: 1. keyring authentication. 2. `.netrc` file authentication." | type: official
- [C20] 全局 config.toml 的 `[pypi-config]` 键：`index-url`、`extra-index-urls`、`keyring-provider`、`allow-insecure-host`（仅 `keyring-provider` 是全局生效，前两者只在 `pixi init` 时写入清单）。 | src: https://pixi.prefix.dev/latest/reference/pixi_configuration/ | quote: "`index-url` and `extra-index-urls` are *not* globals … will only modify the `pixi.toml`/`pyproject.toml` file and are not globally interpreted" | type: official
- [C21] 安装行为开关：`--frozen`/`PIXI_FROZEN`、`--locked`/`PIXI_LOCKED`、`--no-install`/`PIXI_NO_INSTALL`。 | src: https://pixi.prefix.dev/latest/workspace/lock_file/ | quote: "It can also be controlled by the `PIXI_FROZEN` environment variable … `PIXI_LOCKED` … `PIXI_NO_INSTALL`" | type: official

## conflicts
- 锁文件版本号：文档页示例仍是 `version: 6`（"version: 6"，https://pixi.prefix.dev/latest/workspace/lock_file/），而 CHANGELOG 写明 0.68.0（2026-05-07）起为 v7（"This release bump the lock file version to v7"，https://github.com/prefix-dev/pixi/blob/main/CHANGELOG.md）。疑文档示例滞后。

## gaps
- `pylock.toml`（PEP 751）：官方文档/README/CHANGELOG 全文 grep 无任何提及（docs/ 215 个 md，2026-09 克隆，~v0.81.0）；未找到支持或导出的记录。
- pixi.toml 中 `[project]` 是否为 `[workspace]` 别名：文档未提及（`[project]` 仅作为 pyproject.toml 的 PEP 621 表出现）。
- 私有 channel 在 `[workspace]` 之外的键名（如自托管 prefix.dev 企业版 base URL）未见专门键；仅见 `channels` 写 URL + `pixi auth login`。
- conda-forge 之外的默认 channel 未在 manifest 页明示默认值；config `default-channels` 注明 "defaults to only conda-forge" 但仅作用于无 workspace 命令。

## leads
- docs/switching_from/conda.md 有 conda↔pixi 命令对照表；`pixi workspace export conda-environment [--from-lockfile]` 可反向导出 environment.yml。
- pixi-pack/`pixi-unpack`（docs/deployment/pixi_pack.md）可打离线包并附 environment.yml，供 micromamba/conda 使用。
- setup-pixi 全部输入见 https://github.com/prefix-dev/setup-pixi/blob/main/action.yml；输入可用 `SETUP_PIXI_*` 环境变量设置。
