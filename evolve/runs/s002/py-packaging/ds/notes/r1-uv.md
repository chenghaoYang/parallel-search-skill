## claims
- [C1] lock: uv 在 pyproject.toml 旁生成 `uv.lock`，是 universal/cross-platform TOML 锁文件，由 `uv sync`/`uv run` 自动创建更新，可用 `uv lock` 显式更新；格式为 uv 私有。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "`uv.lock` is a *universal* or *cross-platform* lockfile that captures the packages that would be installed across all possible Python markers"; "`uv.lock` is a human-readable TOML file but is managed by uv and should not be edited manually. The `uv.lock` format is specific to uv and not usable by other tools." | type: official
- [C2] pylock.toml (write): `uv export -o pylock.toml` 把 uv.lock 导出为 PEP 751 格式；`uv pip compile requirements.in -o pylock.toml` 也可生成。项目接口仍只用 uv.lock。 | src: https://docs.astral.sh/uv/concepts/projects/layout/ | quote: "uv supports `pylock.toml` as an export target and in the `uv pip` CLI"; "uv will continue to use the `uv.lock` format within the project interface" | type: official
- [C3] pylock.toml (read): `uv pip sync pylock.toml` 或 `uv pip install -r pylock.toml` 可从 PEP 751 文件安装。 | src: https://docs.astral.sh/uv/pip/compile/ | quote: "To sync an environment with a PEP 751 `pylock.toml` file: `$ uv pip sync pylock.toml`" | type: official
- [C4] pylock.toml 起始版本 uv 0.6.15（2025-04-22），同时覆盖读和写；相关 PR #13019/#12955/#12992。 | src: https://github.com/astral-sh/uv/releases/tag/0.6.15 | quote: "This release includes preliminary support for the `pylock.toml` file format, as standardized in PEP 751"; "Add PEP 751 support to `uv pip compile`"; "Add `uv export` support for PEP 751"; "Add `pylock.toml` to `uv pip install` and `uv pip sync`" | type: official
- [C5] meta: 标准元数据放 `[project]`（PEP 621：name/version/dependencies/optional-dependencies/scripts）；uv 专有配置放 `[tool.uv]`；另有 `uv.toml`（省略 `[tool.uv]` 前缀，优先级高于 pyproject.toml）。 | src: https://docs.astral.sh/uv/concepts/configuration-files/ | quote: "If a `pyproject.toml` file is found, uv will read configuration from the `[tool.uv]` table"; "uv will also search for `uv.toml` files, which follow an identical structure, but omit the `[tool.uv]` prefix" | type: official
- [C6] meta: 依赖分布在四个字段。 | src: https://docs.astral.sh/uv/concepts/projects/dependencies/ | quote: "`project.dependencies`: Published dependencies. `project.optional-dependencies`: Published optional dependencies, or \"extras\". `dependency-groups`: Local dependencies for development. `tool.uv.sources`: Alternative sources for dependencies during development." | type: official
- [C7] workspace: 根 pyproject.toml 里 `[tool.uv.workspace]`，键 `members`（必需，glob 列表）与 `exclude`（可选）；成员间依赖用 `[tool.uv.sources]` 的 `{ workspace = true }`（也可为路径字符串）；全 workspace 共享单个 uv.lock；`uv run`/`uv sync` 默认作用于根，`--package` 选成员。 | src: https://docs.astral.sh/uv/concepts/projects/workspaces/ | quote: "you must specify the `members` (required) and `exclude` (optional) keys, which direct the workspace to include or exclude specific directories as members respectively, and accept lists of globs" | type: official
- [C8] workspace: 成员间依赖总是 editable；workspace 强制单一 requires-python（取交集）。 | src: https://docs.astral.sh/uv/concepts/projects/workspaces/ | quote: "Dependencies between workspace members are editable"; "uv's workspaces enforce a single `requires-python` for the entire workspace, taking the intersection of all members' `requires-python` values" | type: official
- [C9] pyver: 项目 Python 下限用 `pyproject.toml` 的 `project.requires-python`（如 `>=3.12`）。 | src: https://docs.astral.sh/uv/concepts/projects/config/ | quote: "Projects may declare the Python versions supported by the project in the `project.requires-python` field of the `pyproject.toml`." | type: official
- [C10] pyver: 钉版本用 `uv python pin` 写 `.python-version` 文件（`--global` 写用户级）；uv 向上搜索工作目录各父级；`.python-versions`（复数）可列多版本供 `uv python install`；CI 可用 `UV_PYTHON` 环境变量覆盖。 | src: https://docs.astral.sh/uv/concepts/python-versions/ | quote: "The `.python-version` file can be used to create a default Python version request"; "A `.python-version` file can be created in the current directory with the `uv python pin` command" | type: official
- [C11] pyver: 安装解释器 `uv python install 3.12`，支持 PyPy/GraalPy/Pyodide；自动下载可用 `python-downloads = "manual"` 关闭；`python-preference` 默认 `managed`。 | src: https://docs.astral.sh/uv/concepts/python-versions/ | quote: "The `python-preference` is set to `managed` which prefers managed Python installations over system Python installations" | type: official
- [C12] build: `uv init` 默认（自 v0.12 起 app 也）生成 packaged 项目，build-system 为 uv 自家后端：`requires = ["uv_build>=0.12.18,<0.13"]`、`build-backend = "uv_build"`。 | src: https://docs.astral.sh/uv/concepts/projects/init/ | quote: "Prior to v0.12, uv did not define a build system for applications by default"; TOML: `requires = ["uv_build>=0.12.18,<0.13"]` / `build-backend = "uv_build"` | type: official
- [C13] build: 可换后端，`--build-backend` 接受 `hatchling`, `uv_build`, `flit-core`, `pdm-backend`, `setuptools`, `maturin`, `scikit-build-core`；`--no-package`/`--bare` 不定义构建系统。 | src: https://docs.astral.sh/uv/concepts/projects/init/ | quote: "You can select a different build backend template by using `--build-backend` with `hatchling`, `uv_build`, `flit-core`, `pdm-backend`, `setuptools`, `maturin`, or `scikit-build-core`." | type: official
- [C14] build: 无 `[build-system]` 则 uv 不安装项目本身只装依赖；`tool.uv.package = true/false` 可覆盖；未声明 build-system 的包回退 `setuptools.build_meta:__legacy__`。 | src: https://docs.astral.sh/uv/concepts/projects/config/ | quote: "If a build system is not defined, uv will not attempt to build or install the project itself, just its dependencies" | type: official
- [C15] sources: `[tool.uv.sources]` 支持五种来源键：index / git / url / path / workspace；仅 uv 识别，其他工具忽略。 | src: https://docs.astral.sh/uv/concepts/projects/dependencies/ | quote: "The following dependency sources are supported by uv: Index, Git, URL, Path, Workspace"; "Sources are only respected by uv." | type: official
- [C16] sources: git 源子键 `tag`/`branch`/`rev`/`subdirectory`/`lfs`；path 源可 `editable = true`/`package = false`；可按 marker 列表给多源；`--no-sources` 忽略整表。 | src: https://docs.astral.sh/uv/concepts/projects/dependencies/ | quote: "httpx = { git = \"https://github.com/encode/httpx\", tag = \"0.27.0\" }"; "bar = { path = \"../projects/bar\", editable = true }" | type: official

## conflicts

## gaps
- `uv pip compile`/`uv export` 的 `--format` 显式枚举值（`requirements.txt`/`pylock.toml`）未在 CLI reference 页逐一核实；官方文档与 release notes 均只演示 `-o pylock.toml` 按文件名推断（0.6.15 有 "Infer output type in `uv export`" #12958）。页面 https://docs.astral.sh/uv/reference/cli/ 未打开（过大）。
- Poetry/PDM → uv 无官方导入命令；社区工具 `uvx migrate-to-uv`（https://osprey-oss.github.io/migrate-to-uv/，secondary，未开原页）支持 Poetry/Pipenv/pip-tools。
- setup-uv 的 `cache-suffix`/`cache-local-path` 等 input 细节未核（需开 github.com/astral-sh/setup-uv README）。
- GitLab CI / Docker 缓存页未打开。

## leads
- uv 自带构建后端 uv_build，参考文档 https://docs.astral.sh/uv/concepts/build-backend/（0.6.15 起有 reference docs，#12803）。
- 对比材料：`uv publish` + PyPI Trusted Publishing 指南在 GitHub integration 页；`uv tool`/`uvx` 读取用户级 `~/.config/uv/uv.toml`。
- `centralized-project-envs` preview feature 可把项目 .venv 放进缓存（layout 页），对 CI 缓存对比有用。
