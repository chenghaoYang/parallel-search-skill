## conflicts
- 捐赠月份：公告/LF 博客称 BeeAI「Later that month」（即 2025-03）捐给 LF，但 LF 官方新闻稿日期为 2025-04-29（SAN FRANCISCO, April 29, 2025）。
- 版本号双轨：openapi.yaml 标 version: 0.2.0，而仓库 release tag 已到 v1.0.3（2025-08-21）——spec 版本与 repo/SDK 版本不同步，未见说明对应关系。
- 现行文档姿态不一致：README/welcome 顶部已挂「ACP is now part of A2A」banner，但正文与全部 spec 页面仍以现在时把 ACP 描述为现行协议（如 "ACP is an open protocol for communication…"），未逐页加 deprecation 标记。

## gaps
- openapi.yaml 未标注 spec 0.2.0 的发布日期；spec 与 SDK 版本对应关系无 changelog 说明。
- 官方页面未见对 Zed「Agent Client Protocol」同名冲突的说明（未逐页核对 about/* 以外页面）。
- Migration guide（beeai-platform 仓库 acp-a2a-migration-guide.mdx）正文未取，无法确认 A2A 对 ACP 概念的逐项映射。
- Registry-Based Discovery 的 registry API 细节未入 spec，BeeAI Platform 实现的接口形态未查。
