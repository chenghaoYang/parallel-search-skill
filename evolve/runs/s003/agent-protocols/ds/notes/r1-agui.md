## conflicts
- 事件总数表述不一：architecture/README 称「16 standardized event types」「~16 standard event types」（https://docs.ag-ui.com/concepts/architecture），而 spec 1.0 称「Thirty-one event types, in eight families」（https://docs.ag-ui.com/spec/1.0/basic/index.md）。changelog 显示 1.0 相对 0.x 新增了 subagents、activity、reasoning 等族，应为 0.x≈16 → 1.0=31 的版本差异，非真正矛盾。
- THINKING_* 措辞不一：concepts/events 页称 deprecated「will be removed in version 1.0.0」，而 1.0 changelog 称 retired 且「translated at the compatibility boundary, not dropped」（文档页疑为旧文）。

## gaps
- 文档页面本身无可见更新日期；版本日期取自 npm registry（@ag-ui/core@1.0.0 发布 2026-09-17T18:27Z，包创建于 2025-04-30）。
- capabilities 的 retrieval/discovery 机制被规范明确留白（见 C23），无标准 endpoint 可引。

## leads
- A2UI 是 Google 的 generative UI 规范，官方 Note 明确与 AG-UI 不同且互补（https://copilotkit.ai/ag-ui-and-a2ui；另 docs.ag-ui.com/concepts/generative-ui-specs 列 MCP-UI、Open JSON UI、A2UI）。勿混入本协议。
- spec 草案区有 Meta Events、Generative UI 等 draft（docs.ag-ui.com/drafts/）。
