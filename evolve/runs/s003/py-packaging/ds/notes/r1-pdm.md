## claims
- [C1] 锁文件默认名 `pdm.lock`，`pdm lock` 创建/覆盖；`pdm install`、`pdm add` 也会自动创建 | src: https://pdm-project.org/en/latest/usage/lockfile/ | quote: "PDM synchronizes dependencies using a locked resolution, normally stored in `pdm.lock`" "the `pdm install` and `pdm add` commands will also automatically create the `pdm.lock` file" | type: official
- [C2] 锁文件含两种格式：`pdm`（默认，`pdm.lock`）与 `pylock`（`pylock.toml`），用 `pdm config lock.format pylock` 切换；另有 env var `PDM_LOCK_FORMAT`、配置键 `lock.format` | src: https://pdm-project.org/en/latest/usage/lockfile/ + https://pdm-project.org/en/latest/reference/configuration/ | quote: "PDM supports two lock file formats: `pdm`(default file name is `pdm.lock`) and `pylock`(default file name is `pylock.toml`). - [C4] `pdm export -f pylock -o pylock.toml` 可把锁导出为 PEP 751 格式（doc 标 Added in 2.24.0）；export 仅支持 requirements.txt 与 pylock | src: https://pdm-project.org/en/latest/usage/lockfile/ | quote: "At present, only the `requirements.txt` format is supported... - [C5] 可用 `-L/--lockfile` 选项或 `PDM_LOCKFILE` 环境变量指定别的锁文件 | src: https://pdm-project.org/en/latest/usage/lockfile/ | quote: "You can specify another lock file with the `-L/--lockfile` option or the `PDM_LOCKFILE` environment variable" | type: official
- [C6] 元数据写在 pyproject.toml 的 `[project]` 表，遵循 PEP 621/631/639；依赖在 `project.dependencies`（PEP 440/508 字符串），可选依赖 `[project.optional-dependencies]`，dev 依赖 `[dependency-groups]` | src: https://pdm-project.org/en/latest/reference/pep621/ | quote: "The project metadata are stored in the `pyproject.toml`. - [C7] 动态版本用 `[tool.pdm]` 下 `version = { source = "file", path = ... }` 配合 `dynamic = ["version"]`；`[tool.pdm]` 的 `distribution = true` 使项目被当作可分发库 | src: https://pdm-project.org/en/latest/reference/pep621/ + https://pdm-project.org/en/latest/usage/project/ | quote: "dynamic = [\"version\"] [tool.pdm] version = { source = \"file\", path = \"mypackage/__version__.py\" }" | type: official
- [C8] workspace 配置键为根项目 pyproject.toml 的 `[tool.pdm.workspace]` `members`（支持路径与 glob），成员是 workspace root 的隐式 editable 依赖 | src: https://pdm-project.org/en/latest/usage/workspace/ | quote: "[tool.pdm.workspace] members = [\"packages/foo\", \"packages/bar\", \"tools/*\"] ... - [C9] workspace 共享根项目的环境与单一锁文件；`pdm install/lock/sync/outdated/info` 必须在根运行 | src: https://pdm-project.org/en/latest/usage/workspace/ | quote: "Workspace members share the workspace root's environment and lock file. - [C10] workspace 支持为实验特性，自 2.28.0 起 | src: https://github.com/pdm-project/pdm/releases/tag/2.28.0 | quote: "Add experimental workspace support for managing local member projects in a shared root lock file. (#1505)" | type: official
- [C11] 旧式 monorepo 做法（workspace 之前）：在 `[dependency-groups].dev` 写 `-e file:///${PROJECT_ROOT}/packages/foo-core`，根目录 `pdm install` 产生一份 `pdm.lock` | src: https://pdm-project.org/en/latest/usage/advanced/ | quote: "you can create only one `pdm.lock` file to lock all dependencies. - [C15] PDM 是 PEP 517 前端；`pdm init` 可选后端，内置模板支持 pdm-backend/setuptools/flit/hatchling/maturin；poetry-core 不支持（不读 PEP 621） | src: https://pdm-project.org/en/latest/reference/build/ | quote: "poetry-core is not supported because it does not support reading PEP 621 metadata" | type: official

- [C23] `pdm import` 支持迁移：Pipenv `Pipfile`、Poetry 的 pyproject.toml 段、Flit 段、`requirements.txt`、setuptools `setup.py`；`pdm init`/`pdm install` 会自动探测可导入文件 | src: https://pdm-project.org/en/latest/usage/project/ | quote: "it now supports: 1. ## conflicts
- PDM 自身所需 Python 版本表述不一：首页 "PDM requires Python 3.10+ to be installed"（https://pdm-project.org/latest/）vs 同页下文 "PDM requires python version 3.9 or higher"（install-pdm.py 段）vs project 页 "PDM run on Python 3.9 and above"（https://pdm-project.org/en/latest/usage/project/）。未裁决，疑为安装器与脚本要求不同或文档滞后。

## gaps
- pylock 何时成为默认格式未给出版本：docs 只说 "It is set to become the default in a future version of PDM"（lockfile 页）。
- `pdm import` 的 CLI 细节（`-f/--format` 取值、是否支持 uv.lock/conda 等更多格式）未查 CLI reference 页，仅确认 project 页列出的 5 种来源。
- workspace 是否支持非 editable 成员、成员独立锁文件：workspace 页仅说共享根锁，未找到独立锁的原句。
- setup-pdm action 缓存的具体目录（是否缓存 `cache_dir` 全部）README 未写明，只给出 `cache`/`cache-dependency-path` 输入。

## leads
- `use_uv`/`PDM_USE_UV`：PDM 可切到 uv 做解析与安装（configuration 页；usage/uv 页未读），workspace 下会生成临时 `[tool.uv.workspace]`。
- lock strategies：`cross_platform`(2.17 起弃用，转 lock-targets)、`static_urls`(2.8.0)、`direct_minimal_versions`(2.10.0)、`inherit_metadata`(2.11.0 默认开)、`--exclude-newer`(2.13.0)。
- pre-commit hooks：`pdm-export`、`pdm-lock-check`、`pdm-sync`（advanced 页）。
