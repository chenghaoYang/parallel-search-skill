## conflicts
- `installer.re-resolve` 默认值：2.0.0 公告写 "add a `installer.re-resolve` option (default: `true`)"（https://python-poetry.org/blog/announcing-poetry-2.0.0），现行配置页写 "Default: `false` … Changed default from `true` to `false` in 2.3.0"（https://python-poetry.org/docs/configuration/）。属版本演进非矛盾，填格子时按现行 default=false。
- basic-usage 称 "Poetry will not install a Python interpreter for you"，但 2.1.0 起有 `python.installation-dir` 配置和 `poetry python` 子命令（2.3.0 changelog "Improve managing free-threaded Python versions with `poetry python`"）——显式托管安装存在，仅「不自动装」成立。
