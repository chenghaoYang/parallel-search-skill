# 术语对齐：需要时再做

陌生领域里，搜不到资料有时是叫法没对上。先弄清少量关键术语、别名和容易混淆的邻近概念，可以省掉大量无效搜索；熟悉且范围清楚的问题通常不需要单独整理词表。

这个思路受 [vocabulary-first](https://github.com/justinatusa/vocabulary-first)（MIT）启发。这里把词表作为可选研究工具，不要求固定数量或固定分类。

从用户的问题里找真正影响理解的词。自己的知识可以提供起点，但遇到不确定的名称就查原论文、术语表、规范或领域内可靠资料。学术领域可能存在几个并行叫法，社区用词也可能很有帮助；没有出现在某份官方词表里，不等于它是错词。

需要记下来时，保存“术语 / 一句话解释 / 别名或易混概念 / 来源与适用范围”就够。关系比数量重要，例如分清帧选择、视觉 token 压缩和模型量化分别减少哪部分工作，而不是为每层凑出若干词。

把新词用到后续检索里，也保留原来的白话表达和常用别名来扩大召回。查询连续无果时，检查是否有名称、语言、版本或相邻领域的差异，可以边改词边继续研究，无须专门等下一轮。

给读者写作时，只解释理解结论所需的概念，通常在第一次出现时说清楚就好。只有用户需要系统入门或反复查阅时才附术语表；不把研究过程中的完整词表强塞到回答开头。
