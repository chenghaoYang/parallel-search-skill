# 词表（vocabulary-first）：先对齐名字，再进入领域

方法来自 [justinatusa/vocabulary-first](https://github.com/justinatusa/vocabulary-first)（MIT）：领域词表是人与模型之间的接口。
**命名越准，协作越快**——工人拿标准词去搜，一手来源命中更快；读者先看词表，5 分钟建立认知；主 agent 用同一套词，
taxonomy、简报、成稿不会各说各话。用户的话是外行说法时，先映射成标准名再派活。

## 三件套 + 扩展

| 层 | 作用 | 数量 |
|---|---|---|
| seed（入口词） | 一说就定位到这个领域 | 8–12 |
| core（骨架词，terms of art） | 撑起整张领域地图的专名 | 20–40 |
| shibboleths（圈内暗号） | 高信号行话，各注明**易混邻域** | 5–10 |
| threshold（门槛概念） | 跨过才「开窍」的概念，常可直接当分类轴 | 3–5 |
| entry（外行 → 标准名） | 用户/读者的白话 → preferred term | 5–10 对 |
| edges（概念边） | `A —关系→ B`，把词连成图，不只是清单 | 10–15 |

骨架词分两类用：**对象词**（东西，进 grid 当行）、**问题词**（现象/规则，问题化后进 grid 当列）。
暗号和门槛概念里的对立（如 轮次型 vs 条目型、REST vs RPC）是现成的分类轴。

## `<dir>/vocab.md` 文件格式

```
# <领域> 词表
状态：✅ 官方出处已核 | ⚠ 未核验（R0 生成）| ⊘ 官方无此词（社区叫法，已查过）

## seed（入口）
- <词> | <一句话白话> | 激活：<什么语境> | ⚠

## core（骨架）
- <词> | <一句话白话> | <备注/别名> | ⚠

## shibboleths（暗号）
- <词> | <何时出现> | 易混：<邻域> | ⚠

## threshold（门槛概念）
- <概念> | <为什么跨过才开窍>

## entry（外行 → 标准名）
- <外行说法> → <preferred term>

## edges（概念边）
- <A> —<关系>→ <B>

## 待补词
- <叫不出标准名的东西：白话描述、大概在哪个邻域>
```

## 反向生成（R0，主 agent，不搜索）

- 只凭已有知识写 v0，全部标 `⚠`。**宁可多写待补词，不编官方出处**——没把握的官方叫法就进「待补词」。
- 用户任务里出现的每个名词都过一遍：能映射到标准词的写进 entry；映射不了的进「待补词」。
- 词表是给本次调研用的，不求全：范围外的词不收；一个词在任务里没作用也不收。

## 核验（R1 词表工人）

简报模板见 `references/worker.md`。工人对官方 glossary、规范索引页、reference 的术语节逐词判：

1. 官方确实这么叫 → 给 URL + 原句（claims 一词一条）；
2. 官方叫法不同 → 记正确叫法 + URL + 原句，这是最有价值的一类；
3. 官方没这个词（社区/口语叫法）→ 标 `⊘`，写明查过哪些页；
4. 官方页上有、词表漏了的高信号词 → 记 leads。

收束时并回 `vocab.md`：错词换官方叫法、漏词补上、`⚠→✅`。之后每轮工人 leads 里报的官方叫法也随手并进来。

## 缺词急救（卡住先补词）

某个格子反复 `❓`、工人返回「没找到相关页面」、leads 报「官方另有叫法」——先怀疑是**词没对上**，不是来源不存在。
动作：派一份词表简报（只补这个词的官方叫法和邻词），下一轮再用标准名派调研简报。
反过来，工人搜索时必须用简报词表切片里的标准词，不用用户的外行说法。

## 词表怎么喂全程

| 去处 | 用法 |
|---|---|
| `grid.md` 行 | 对象词 + 预期变体 |
| `grid.md` 列 | 问题词问题化（「这一列回答什么问题」） |
| 分类轴 | 暗号/门槛概念里的对立 |
| 工人简报 | 词表切片：本简报相关的标准词 + 用户外行说法映射，一行一个 |
| report §1「先认识这些词」 | 从 vocab.md 压缩：每词一行一句，暗号带易混邻域，entry 成小表；`⚠` 照登不编出处 |
| 下一场调研 | 任务同领域时可把 vocab.md 拷去当起点，先核验再增删 |

## 回流

终审发现词表走样（官方不这么叫）→ 改 `vocab.md` 和成稿两处；调研中新学的词（leads、conflicts 里）→ 收束时并进词表。
词表跟成稿一样是交付物的一部分，不是草稿。
